# 2026-09-21 개정: 무작위 초기 배치와 단회 배치 시연

원본 제출 PDF는 보존한다. 본 문서는 이번 대화에서 확정된 시연 수집 변경만 기술한다.

## 현재 범위

- π0는 보류한다.
- 현재는 통합 데이터셋 하나를 수집한다. 재배치 포함/제외 비교는 보류한다.
- 첫 파지에 성공하고 운반 중 파지를 유지한 시연만 사용한다.
- 파지 실패 시 즉시 해당 시연을 종료하고 학습 데이터에서 제외한다. 재파지 시연도 현재 수집 대상이 아니다.
- 그리퍼 해제 전 정렬은 허용한다. 해제 후에는 재파지·재배치를 하지 않는다.
- 세 블록 모두 최종 배치 기준을 충족하고 낙하가 없어야 보존한다. 기존처럼 두 블록만 성공한 시연은 보존하지 않는다.

## 초기 배치

기존 공급 슬롯 중심에서 위치 ±5 mm → ±30 mm, 수평 방향 ±10° → ±60°로 확대한다.
블록의 크기는 고정한다. 바닥에 평평하게 놓인 상태의 위치와 yaw를 무작위화하며, 초기 뒤집힘이나 적층은 포함하지 않는다.
공급 슬롯은 매번 무작위 순열로 할당한다. 중심 반경 0.13~0.26 m, 벽 영역과의 여유 15 mm,
블록 사이 분리축 기준 여유 10 mm를 만족하지 않는 배치는 다시 추출한다. 이 기하 조건만으로 IK·파지 성공을 보장하지는 않는다.

실제 초기 자세, 기하 배치 재추출 횟수, 시연 실패 사유를 기록한다. 성공 시연만 선별하면 어려운 자세가
빠질 수 있으므로 수집 성공률과 보존된 초기 자세의 분포를 함께 확인해야 한다.

## 파지 확인과 기록

시연 생성기는 블록이 초기보다 15 mm 이상 들렸고 양쪽 턱과 접촉하며 TCP 50 mm 이내에 있는지 확인한 뒤 운반한다.
운반·해제 전 정렬 중에는 양턱 접촉을 계속 확인한다. 이 확인에는 시뮬레이터 참값을 사용한다.
학습 입력은 front/wrist/top 영상과 관절 상태이며, 파지 참값은 입력에 추가하지 않는다.
학습 정책 실행에 확인 장치를 적용하는 것은 아직 확정하지 않았다. 성공 시연만으로 학습한 정책이
빈손 운반이나 해제 후 재조정을 절대 하지 않는다고 보장하지 않는다.

## 환경과 평가의 한계

이번에는 기존 v2 mortarB 환경을 유지한다. 세계 좌표 고정 결합과 목표 슬롯 기준의 베드 생성은
기존 모델의 한계이며, 실제 모르타르나 부재 간 결합의 검증으로 해석하지 않는다.
새 실험에서는 IoU를 회전 직육면체의 교집합/합집합 부피로 계산하여 roll/pitch도 반영한다.
앞면 이격은 하나의 실제 앞면을 구성하는 네 코너로 계산한다. 새 지표 버전은 `oriented_polyhedron_v1`이다.
기존 결과 JSON을 덮어쓰지 않으며, 구 지표 결과와 새 지표 결과를 직접 성능 개선으로 비교하지 않는다.
이번 변경으로 기존 정책 비교 결과가 소급해 검증되는 것은 아니다.

## 본실험: 데이터셋 1개, 정책 3개

2026-09-21 사용자 실행 승인에 따라 다음 설정을 고정한다. 데이터 양·카메라 수·교란 비율별 조건을 추가하지 않는다.

| 항목 | 설정 |
|---|---|
| 데이터 | 완전 성공 시연 240개, 최대 시도 2,000회. 실패 영상/행동 제외, 원인 로그 보존 |
| 분할 | 에피소드 0~199 학습, 200~239 검증. 프레임 단위로 섞지 않음 |
| 정규화 | 학습 200개에서만 통계 집계. 전체 통계는 별도 파일로 보존 |
| 정책 | ACT 40k 스텝, Diffusion 60k 스텝, SmolVLA 20k 스텝(VLM 동결) |
| 배치 크기 | ACT·Diffusion 32, SmolVLA 16. 설정 차이를 공개하며 동일 연산량 비교라고 주장하지 않음 |
| 카메라 | 모든 정책에 front/wrist/top 3대 |
| 관측 갱신 | 모든 정책 10스텝(0.5초), 물리·제어 주기는 공통 |
| 학습 반복 | 시드 1000·1001·1002, 총 9회. 조건 탐색이 아닌 독립 학습 반복 |
| 체크포인트 | 사전에 정한 마지막 스텝 사용. 검증 손실은 5,000스텝마다 관찰 |
| 검증 실행 | 학습당 초기 상태 40000~40019, 20회 |
| 최종 시험 | 학습당 초기 상태 50000~50099, 100회. 전문가 성공 여부로 시험 상태를 선별하지 않음 |
| 평가 | 무교란, 같은 넓은 초기 배치 범위, 모든 에피소드 포함. 추론 난수도 기록 |
| 추가 진단 | 해제 후 재파지 관측 횟수, 재파지 없는 전체 성공 수, 최종 자세 저장 |

학습된 정책이 해제 후 재파지하지 않는다는 보장은 없다. 평가에서 양턱 접촉 이력과 그리퍼 열림 후
재접촉으로 위반을 기록하며, 이 자동 진단은 영상으로 교차 확인할 필요가 있다. 별도 파지 차단 장치는 적용하지 않는다.

실행: `bash sim/run_clean_experiment.sh --start`. 진행 상태는 `sim/outputs/clean_experiment_status.json`,
수집 진행은 데이터셋의 `collection_progress.json`, 결과는 `sim/outputs/clean_experiment_results.csv`에 기록한다.
학습 정체가 30분 지속되면 해당 자식 프로세스를 종료하고 저장된 체크포인트에서 최대 3회 시도한다.

## 실행

`sim/collect.py --clean-single-pass --valid-supply --pos-rand 0.03 --yaw-rand 60`으로 수집한다.
`--target-kept`는 보존할 시연 수, `--episodes`는 최대 시도 수다. 실패 시연의 영상/행동은 학습 세트에서
제외하지만 원인·초기 상태 로그는 남긴다. 최초 예시는 `sim/data/v3_2p1_joint_image_preview`에 저장한다.
