## 이 문서의 목적

새 실험을 설계하면서 아직 정하지 못한 항목들이 있습니다. 이 항목들을 **다른 연구들은 어떻게 정했는지** 조사해 주세요.

- **최종 결정을 요청하는 것이 아닙니다.** 결정은 팀이 함께 합니다.
- 필요한 것은 "어떤 논문이, 어떤 상황에서, 무엇을, 얼마로 정했는가"와 그 출처입니다.
- 조사하다 보면 의견이 생길 텐데, **추천안은 선택 사항**입니다. 적는다면 근거 논문과 확신 정도(높음/중간/낮음)를 같이 적어 주세요.
- 딥러닝을 깊이 몰라도 됩니다. 각 항목에 "무엇을 찾으면 되는지"를 적어 두었고, 논문에서 찾는 위치도 정리했습니다.

## 1. 우리 실험 한눈에 보기

| 항목 | 내용 |
|---|---|
| 하는 일 | 시뮬레이터(MuJoCo) 안에서 로봇팔(UR10e)이 실제 크기 벽돌(190×90×57 mm)로 3단 일자 벽(벽돌 16회 배치)을 쌓음 |
| 로봇을 가르치는 방법 | **모방학습:** 정답을 아는 스크립트가 쌓는 모습(시연)을 1,000번 보여 주고, 신경망(정책)이 그걸 따라 하도록 학습 |
| 알고 싶은 것 | 학습된 정책은 그대로 두고, 바깥에서 **① 잡았는지 확인(하중 센서·집게 각도) ② 놓기 전 위치 보정(카메라) ③ 놓은 뒤 재검사·재배치(카메라)**를 켜고 끄면 벽 완성률이 각각 얼마나 오르는가 |
| 실험 방식 | 세 가지 제어를 켬/끔으로 모두 조합한 8조건을 같은 시험 배치에서 비교 |
| 이미 정한 것 | 학습 데이터셋 = 합격한 벽 1,000개 (나누지 않음) · 학습은 벽돌 한 장 단위로 잘라서 · 학습 seed 3개 · 판정 = 표준시방서 허용오차 |

## 2. 용어 풀이 (이 문서에 나오는 것만)

| 용어 | 쉬운 뜻 |
|---|---|
| 정책 (policy) | 카메라 영상과 관절 값을 보고 다음 동작을 정하는 신경망. 우리 실험의 "학생" |
| 시연 (demonstration) | 정책이 따라 배울 모범 동작 기록 한 번 |
| 에피소드 | 시연이나 시험의 한 회차. 우리는 "벽돌 한 장 집어서 놓기"가 에피소드 하나 |
| 목표 조건 (goal-conditioning) | 정책에게 "이번엔 어디에 놓아라"를 입력으로 같이 주는 방식 |
| 행동 묶음 (action chunk) | 정책이 한 번에 예측하는 동작 여러 스텝. ACT·Diffusion Policy가 쓰는 방식 |
| ACT, Diffusion Policy | 요즘 로봇 모방학습에서 가장 많이 쓰는 정책 구조 두 가지 |
| 학습 seed | 같은 데이터로 학습해도 결과가 조금씩 달라지게 만드는 무작위 시작값. 3개면 3번 따로 학습 |
| 학습량 (에폭 / 스텝) | 에폭 = 데이터 전체를 몇 번 훑었는지, 스텝 = 신경망을 몇 번 고쳤는지 |
| 검증 / 시험 | 검증 = 설정을 정할 때 보는 자료, 시험 = 설정을 다 고정한 뒤 성적을 내는 자료 |
| 초기 배치 | 시험을 시작할 때 벽돌들이 처음 놓인 위치·방향 |
| 교란 (perturbation) | 시험 도중 일부러 벽돌을 밀거나 방해해서 강건성을 보는 것 |
| 완성률 | 벽을 시방서 허용오차 안으로 다 쌓은 회차의 비율 |

## 3. 조사할 항목

**우선순위 1**(수집 전에 꼭 필요)부터 해 주세요. 항목마다 **논문 3~5편**이면 충분합니다.

### 우선순위 1

#### 항목 1. 목표 정보를 정책에 어떤 형식으로 주는가

| | |
|---|---|
| 우리가 정할 것 | 정책에게 "몇 단, 몇 번째 자리, 온장/반장"을 알려줄 형식. 후보는 **자리 번호(숫자), 목표 좌표(도면값), 목표 이미지(완성 모습 사진)** |
| 왜 중요한가 | 같은 공급대에서 벽돌을 집어도 놓을 곳이 매번 다르므로, 목표를 어떻게 알려주느냐가 정책 성능을 좌우함 |
| 찾을 것 | 여러 위치에 물체를 놓는 모방학습 연구가 목표를 숫자·좌표·이미지·언어 중 무엇으로 줬는지, 그 비교 결과가 있는지 |
| 검색어 | goal-conditioned imitation learning, task conditioning, multi-task pick and place, target pose conditioning, goal image |
| 출발점 | Lynch et al. 2019 "Learning Latent Plans from Play" (CoRL) · BrickCraft (Yu et al. 2026, arXiv:2605.07605, preprint) |

#### 항목 2. 긴 작업을 짧게 쪼개 학습하는 방식의 근거 (이미 정함, 근거 보강용)

| | |
|---|---|
| 우리가 정한 것 | 벽 하나(16회 배치) 시연을 벽돌 한 장 단위로 잘라 학습하고, 다음 벽돌은 도면 순서표가 정함 |
| 찾을 것 | 긴 작업을 하위 작업으로 나눠 학습한 연구, 통째로 학습한 연구, 둘을 비교한 결과. 나누는 기준(물체 하나 단위, 동작 단위 등) |
| 검색어 | long-horizon imitation learning, task decomposition, subtask segmentation, skill chaining, object-centric subtask |
| 출발점 | MimicGen (Mandlekar et al. 2023, CoRL, arXiv:2310.17596) · BrickCraft (위와 같음) |

#### 항목 3. 어떤 정책(모델)들을 비교하는가

| | |
|---|---|
| 우리 안 | ACT, Diffusion Policy 2개 (SmolVLA·π0.5는 여유가 있을 때) |
| 찾을 것 | mm 정밀도가 필요한 집기·놓기·조립 연구에서 어떤 정책을 썼고 성능 차이가 어땠는지. 건설 분야 모방학습에서 쓴 정책 |
| 검색어 | ACT diffusion policy comparison precise manipulation, imitation learning construction robot, brick assembly imitation learning |
| 출발점 | ACT (Zhao et al. 2023, RSS, arXiv:2304.13705) · Diffusion Policy (Chi et al. 2023, RSS, arXiv:2303.04137) · Huang et al. 2027 (J. Comput. Civ. Eng., doi:10.1061/JCCEE5.CPENG-7917) |

#### 항목 4. 학습량과 학습 설정을 어떻게 정하는가

| | |
|---|---|
| 우리가 정할 것 | 정책마다 학습을 몇 스텝(또는 몇 에폭) 할지, 배치 크기 등. **정책끼리 학습량을 어떻게 맞췄는지**가 핵심 |
| 왜 중요한가 | 지난 실험에서 데이터 양이 다른 비교를 같은 스텝으로 학습해 결과 해석이 흐려졌음 |
| 찾을 것 | 각 논문의 학습 스텝·에폭·배치 크기, 데이터 양이 다를 때 학습량을 어떻게 맞췄는지, 학습 seed를 몇 개 썼는지 |
| 검색어 | training budget imitation learning, number of epochs diffusion policy, hyperparameters ACT, seeds robot learning |
| 출발점 | robomimic (Mandlekar et al. 2022, CoRL, arXiv:2108.03298) · LeRobot 기본 설정 (github.com/huggingface/lerobot) |

#### 항목 5. 카메라를 몇 대, 어디에 두는가

| | |
|---|---|
| 우리 안 | 작업대 위 고정 RGB-D 카메라 기본, 가림이 심하면 시점 추가 |
| 찾을 것 | 집기·놓기 연구의 카메라 대수·위치(고정/손목)·해상도. 손목 카메라 유무에 따른 성능 차이 |
| 검색어 | camera placement imitation learning, wrist camera ablation, multi-view manipulation policy |
| 출발점 | 우리 팀 조사 [`00_공통/선행연구_목표정밀도_조사.md`](../00_공통/선행연구_목표정밀도_조사.md)의 "Curse of Precision" 항목(손목 카메라 제거 시 정밀도 변화) |

#### 항목 6. 시험 시작 위치를 어느 범위로 흩는가

| | |
|---|---|
| 우리가 정할 것 | 공급대 위 벽돌의 처음 위치·방향을 얼마나 무작위로 흩을지 |
| 찾을 것 | 집기·놓기 벤치마크가 물체 처음 위치를 몇 cm, 몇 도 범위로 흩는지, 범위를 넓히면 성능이 얼마나 떨어지는지 |
| 검색어 | initial state distribution manipulation benchmark, object pose randomization imitation learning, generalization to initial positions |
| 출발점 | robomimic · 우리 팀 조사 문서의 ManiSkill3 StackCube 항목 |

### 우선순위 2

#### 항목 7. 시험을 몇 번 하고 결과를 어떻게 보고하는가

| | |
|---|---|
| 찾을 것 | 각 논문이 조건당 시험을 몇 회 했는지, 신뢰구간이나 통계 검정을 보고했는지, 같은 시작 배치로 짝지어 비교했는지 |

|---|---|

#### 항목 9. 교란을 넣어 시험하는가

| | |
|---|---|

| 검색어 | perturbation robustness imitation learning, disturbance evaluation manipulation |
| 출발점 | DART (Laskey et al. 2017, CoRL, arXiv:1703.09327) |

#### 항목 10. 잡았는지 확인하는 방법 (하중 센서·집게 폭)

| | |
|---|---|

| 검색어 | grasp success detection, gripper width force sensor grasp verification, failure detection manipulation |
| 출발점 | FAIL-Detect (Xu et al. 2025, RSS, arXiv:2503.08558) · Sentinel (Agia et al., arXiv:2410.04640) · Rewind-IL (Zheng et al. 2026, RA-L) |

#### 항목 11. 놓기 전 보정·놓은 뒤 재배치 선례

| | |
|---|---|
| 찾을 것 | 학습 정책 밖에서 카메라·센서로 위치를 고쳐 주는 방식, 조적 로봇이 놓은 벽돌을 다시 맞추는 방식, 그 허용오차와 횟수 |
| 검색어 | visual servoing placement correction, residual correction imitation learning, robotic bricklaying pose correction |
| 출발점 | In situ Fabricator (Giftthaler et al. 2017, Construction Robotics) · 랩미팅 문헌정리 [`중간발표1/중간발표1_261012_랩미팅_문헌정리.md`](중간발표1/중간발표1_261012_랩미팅_문헌정리.md) 3절 |

#### 항목 12. 집게와 벽돌 물성

| | |
|---|---|
| 찾을 것 | 벽돌을 다루는 로봇이 쓴 집게 종류(평행 집게, 흡착 등)와 벌림 폭, 벽돌(점토·콘크리트)의 밀도와 마찰계수 값 |

## 4. 논문에서 설정값 찾는 법

설정값은 본문 앞쪽보다 뒤쪽에 숨어 있는 경우가 많습니다.

| 찾는 것 | 주로 있는 곳 |
|---|---|
| 정책 종류, 학습량, 하이퍼파라미터 | "Implementation Details", "Training Details", 부록(Appendix)의 표 |
| 카메라, 시작 위치 범위, 시간 제한 | "Experimental Setup", "Tasks", "Environment" |
| 시험 횟수, 성공 기준 | "Evaluation", 결과 표의 캡션 |
| 비교 결과 | "Ablation", "Results" |

코드가 공개된 논문은 GitHub의 설정 파일(config, yaml)에 실제 값이 정확히 적혀 있습니다.

## 5. 조사 규칙

1. **출처 링크를 꼭 남겨 주세요.** arXiv 번호, DOI, 학회 페이지 중 하나.
2. **숫자는 원문 그대로** 적고, 원문 위치(표 번호, 쪽)를 같이 적어 주세요.
3. **AI 답변이나 요약 블로그를 출처로 쓰지 마세요.** 원문에서 직접 확인한 것만 적습니다. 확인하지 못했으면 "미확인"이라고 적어 주세요.
   - 실제 사례: 최근 "KCS 표준시방서에 이런 허용오차가 있다"는 AI 답변을 받았는데, 원문에서는 찾을 수 없었습니다.
4. 동료심사 전 논문(arXiv만 있는 것)은 "preprint"로 표시해 주세요.
5. 우리와 상황이 다른 점(실기/시뮬레이션, 물체 크기, 로봇 종류)을 같이 적어 주세요. 그대로 가져와도 되는지 판단할 때 필요합니다.
