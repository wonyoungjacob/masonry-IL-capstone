## 2. 연구 원칙 (반드시 지킴)

1. **정답 좌표는 시연 생성(역기구학 대본), 학습 라벨, 채점에만 쓴다.** 정책 관측(`observation.*`)에 벽돌 참값 자세를 넣지 않는다. 목표 정보는 도면(설계 자리)에서 계산한 값이라 넣어도 된다.
2. **끊긴 실행의 부분 결과를 합치지 않는다.** 중단되면 그 회차를 처음부터 다시 실행한다.
3. 실행마다 **설정 파일, git 커밋 해시, 자산 커밋 해시, 데이터 해시**를 결과와 함께 저장한다.
4. **초기 배치 시작값(seed) 범위를 섞지 않는다.** 이 작업은 파일럿 범위만 쓴다.

| 용도 | 시작값 범위 | 이 작업에서 |
|---|---|---|
| 파일럿 | 700000 ~ 700049 | **사용** |
| 본 수집 | 710000 ~ 719999 | 사용 금지 (예약) |
| 검증 | 720000 ~ 720999 | 사용 금지 (예약) |
| 시험 | 730000 ~ 730999 | **사용 금지 (잠금)** |

5. 파일럿 데이터는 **본 데이터셋에 넣지 않는다.** 파일은 보고 후 사용자 지시가 있을 때 지운다.

- `sim/wall3/scene.py`: 3절 사양대로 장면 구성(받침대, 벽 자리 16개, 공급대 칸 16개, 카메라 3대, 모르타르 단별 깔기)

### 단계 3. 평가 코드

- `sim/wall3/spec_metrics.py`: 평가지표 md를 **그대로** 구현
  - 시방 5항목: ① 가로줄눈 두께(1–2단·2–3단 7 ~ 13 mm, 1단 아랫면–바닥 0 ~ 3 mm) ② 선 및 면 ③ 수직도 ④ 평면상 위치 ⑤ 벽 두께. 길이 비례 + 하한 2 mm(이 벽은 ②③④ 모두 2.0 mm)
  - 측정점은 모든 벽돌의 모서리 8개
  - 존재 조건(16자리 채움: 수평 45 mm, 높이 28.5 mm 안, 기울기 45° 미만, 온장·반장 따로 대응)
  - 벽돌별 3D IoU(`sim/brick_sim/volume.py`의 교집합 계산을 import해서 사용)
  - 출력: 항목별 측정값(mm), 허용오차, 합격 여부, 시방 합격 여부, IoU 16개·평균·최솟값
- `sim/tests/test_wall3_spec_metrics.py`: 평가지표 md 6절 시험
  - 설계 자세 그대로 → ① 10 mm(1단 아랫면 0 mm), ②③④ 0, ⑤ 0, IoU 1, 시방 합격
  - 벽돌 하나를 수평으로 1°, 2° 회전 / 2 mm, 4 mm 앞뒤로 밀기 → 평가지표 md 2.6절의 걸리는 크기와 맞는지
- **완료 기준:** 시험 전부 통과

### 단계 4. 역기구학 대본

- `sim/wall3/expert.py`: UR10e용, 위에서 수직으로 집고 놓기. 정답 좌표 사용 허용(시연 생성)
- 벽돌 한 장 = 철수 자세에서 출발 → 공급 칸에서 집기 → 운반 → 놓기 → 놓은 뒤 철수 자세로 복귀
- **재시도·다시 집기 금지.** 실패하면 그 벽을 폐기하고 사유 기록
- **벽돌마다 시작·끝 스텝을 기록**: 시작 = 철수 자세에서 출발하는 스텝, 끝 = 벽돌이 받침(바닥·아래 단 모르타르)에 얹혀 정지하고 집게가 철수 자세로 돌아온 스텝
- 목표: **벽돌 한 장 10초 이내**
- **화면 보기:** 수집 과정을 눈으로 확인할 수 있게 두 가지를 만든다
  - `sim/wall3/view_collect.py` (+ 실행 스크립트 `sim/wall3/view_collect.sh`): MuJoCo 뷰어 창(`mujoco.viewer.launch_passive`)을 띄워 대본이 벽을 쌓는 모습을 실시간 속도로 보여 준다. 시작값과 벽 개수를 인자로 받는다. 창 렌더링은 EGL이 아니라 화면용이므로 `MUJOCO_GL=egl`을 쓰지 않는다. 데스크톱 화면에 연결된 터미널에서 사람이 실행하는 용도이며, 에이전트 실행 환경에 화면이 없으면 만들고 사용법만 보고한다. 기존 `sim/view_demo.py` 방식을 참고하되 기존 파일은 고치지 않는다
  - 녹화: 벽 하나를 쌓는 과정을 자유 시점 카메라(벽 전체와 공급대가 보이게) + 정책 카메라 3대를 한 화면에 붙여 mp4로 저장하는 옵션. 원본 영상은 `sim/outputs/wall3/` 아래에 두고 git에 올리지 않음
- **완료 기준:** 스모크 3벽이 끝까지 쌓이고, 벽돌별 시작·끝 표시가 16개씩 정상. 스모크 1벽을 녹화해 보고서용으로 짧게 줄인 영상(10 MB 이하)을 `01_사기설/근거_우분투_wall3_파일럿/`에 올림

### 단계 5. 기록과 데이터셋 변환

- 벽 단위 원자료: 매 스텝 카메라 3대(128²), 관절 6 + 집게, 행동(관절 목표 6 + 집게), **집게 각도, 손목 힘·토크**, 벽돌 참값 자세(채점·라벨용), 벽돌별 시작·끝 스텝, 벽 단위 판정(시방 5항목, **벽돌별 IoU**)
- LeRobot 데이터셋(v3): **벽돌 한 장 = 에피소드 1개**로 잘라 저장
  - 정책 관측: 카메라 3대, 관절 상태, **목표 정보**(도면에서 계산한 그 벽돌의 목표 자세 x·y·z·yaw + 온장/반장 표시)
  - 정책 관측에 넣지 않는 것: 벽돌 참값 자세, 힘·토크, IoU, 판정 결과 (별도 메타데이터로 저장)
  - 에피소드 메타데이터: 벽 번호, 자리 번호(단·순서), 초기 배치 시작값
- **완료 기준:** 스모크 3벽이 48개 에피소드로 변환되고, LeRobot으로 다시 읽었을 때 프레임 수·카메라·목표 정보가 맞음

### 단계 6. 파일럿 수집 (벽 50개)

- 시작값 700000 ~ 700049로 벽 50개 시도
- 각 벽: 대본으로 쌓기 → 마지막 벽돌 뒤 2초 정착 → 평가 → **시방 합격한 벽만 데이터셋에 포함**, 탈락은 사유(어느 항목, 어느 벽돌)와 함께 기록
- 중단된 벽은 합치지 않고 처음부터 다시
- 대량 수집은 속도를 위해 화면 없이(EGL) 돌린다. 대신 **10벽마다 1벽을 녹화**해 진행을 눈으로 확인할 수 있게 한다(원본은 git에 올리지 않음)
- **완료 기준:** 50개 시도 완료, 결과 요약 저장
