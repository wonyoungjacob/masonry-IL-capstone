학습 없이 제어만으로 3단 벽 쌓기: 구현 로드맵

같은 장면(UR10e, 2F-140, 벽돌 16장, 3단)을 학습 정책 없이 측정, 계산, 확인만으로 쌓는다면 무엇을 어떤 순서로 만들어야 하는지 정리했습니다. 점선 밑줄 용어는 누르면 용어 설명으로 갑니다.

0한눈에

출발점

시연을 만든 대본이 이미 제어만으로 벽을 쌓는다. 다만 시뮬레이터 참값을 세 군데에서 읽는다.

할 일

참값 세 곳을 센서로 바꾸고, 참값 덕에 없던 실패 처리, 모르타르 공정, 보정, 잡음을 만든다.

방법

참값을 한 곳씩 센서로 바꾸며 매번 100벽을 잰다(사다리). 어디서 정확도를 잃는지 한 단계씩 드러난다.

기간 · 장비

시뮬레이션 안에서 약 11~13주(1명 + Claude Code). 학습이 없으니 GPU 학습이 필요 없다.

3벽돌 한 장의 흐름 (상태 기계)

로봇이 지금 어느 단계(상태)에 있는지와, 어떤 조건에서 다음 상태로 옮겨 가는지를 미리 다 정해 둡니다. 초록은 성공했을 때, 빨강은 실패했을 때 가는 곳입니다. 재시도 횟수와 허용치는 초안이며, 통합 평가의 실패 기록을 보고 정합니다.

4방법: 참값을 한 곳씩 센서로 바꾸는 사다리

한 번에 여러 개를 바꾸면 성적이 떨어졌을 때 어디서 떨어졌는지 모릅니다. 학습 분석에서 실제로 겪은 문제입니다. 그래서 한 칸씩 내려가며 칸마다 100벽을 잽니다.

9용어

참값시뮬레이터가 아는 정답 위치 · 자세. 실제 로봇은 알 수 없다. 우리는 채점과 감사에만 쓴다.
순기구학 / 역기구학관절 각도 → 손 위치 계산 / 손 위치 → 관절 각도 계산.
궤적 · 최소 저크 곡선시간에 따라 손이 지나갈 길 / 가속도 변화(저크)가 가장 작은 부드러운 길.
PD · PID 서보목표와 현재의 차이(P), 차이의 변화 속도(D), 차이의 누적(I)으로 모터 힘을 정하는 기본 제어. 우리 팔은 PD(kp 5000, kd 500), 집게도 PD.
역동역학 앞먹임궤적을 따라가는 데 필요한 힘을 미리 계산해 명령에 더함. 서보가 오차를 본 뒤에야 따라가는 지연을 줄인다.
가드 무브힘을 지켜보며 움직이다가 닿으면 멈추는 동작.
임피던스 제어로봇을 '용수철 + 댐퍼'처럼 행동하게 하는 힘 제어. 밀리면 부드럽게 물러난다. 토크로 직접 제어하는 로봇에 맞다.
어드미턴스 제어같은 효과를 '힘 센서 → 위치 목표 수정'으로 낸다. UR10e 같은 위치 서보 로봇에 맞다.
힘 · 토크 센서손목에 걸리는 힘(3축)과 비트는 힘(3축)을 잰다. UR10e e-Series는 내장.
시각 서보 (닫힌 고리)카메라로 재고 → 움직이고 → 다시 재기를 오차가 작아질 때까지 반복. '한 번 보고 움직이기'보다 견고하다.
RGB-D · 점구름컬러 + 깊이(화소마다 카메라까지 거리) 영상 / 깊이 영상을 3차원 점들로 바꾼 것.
평면 맞춤 · 모델 정합 (ICP)점들에 평면을 맞춰 높이 · 기울기를 얻음 / 아는 모양(190×90×57 mm)을 점들에 겹쳐 위치를 찾음.
내부 · 외부 파라미터, 손-눈 보정카메라 자체의 성질(초점거리 · 중심) / 카메라가 어디서 어느 쪽을 보는지 / 카메라와 로봇의 상대 위치를 재는 절차.
상태 기계 · 행동 트리단계와 전이 조건을 표로 정한 것 / 같은 일을 나무 구조로 정리해 재사용하기 쉽게 한 것.
인터록조건이 맞지 않으면 다음 동작을 막는 장치. 예: 앞 자리 확정 전에는 다음 벽돌 금지.
페일세이프확인이 안 되거나 고장 나면 안전한 쪽(멈춤)으로 가게 하는 설계.
감시 타이머 (watchdog)한 상태가 정해진 시간 안에 끝나지 않으면 이상으로 보고 멈춤.
오차 예산 · RSS전체 허용 오차를 원인별로 나눠 배정한 표 / 독립 오차들의 합을 제곱합의 제곱근으로 계산(√(0.3² + 0.8² + … ) ≈ 1.8).
FMEA고장 형태와 영향 분석. 일어날 수 있는 실패를 모두 적고 각각의 영향 · 대책을 정리.
실패 주입 시험일부러 실패를 넣어 복구 규칙이 작동하는지 확인하는 시험.
지그물건을 정해진 위치 · 방향에 놓이게 하는 받침 · 틀.
구조화된 환경물건 위치를 미리 정돈해 로봇이 덜 보고도 일할 수 있게 한 환경.
사이클 타임벽돌 한 장(또는 벽 하나)을 끝내는 데 걸리는 시간.
토탈스테이션 · 레이저 트래커측량 기구. 멀리 있는 표적까지의 거리 · 각도를 재 위치를 매우 정확히 안다.
