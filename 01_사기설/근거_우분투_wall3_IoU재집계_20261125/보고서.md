## 3. [B] 벽돌별 3D IoU 재집계

### 3.1 정의

| 항목 | 정의 |
|---|---|
| 자리별 IoU | 롤아웃 때 채점 코드(`sim/wall3/spec_metrics.py` 맨 끝 '벽돌별 3D IoU' 부분)가 계산해 `eval.iou`에 남긴 값을 그대로 썼다. 짝지은 벽돌 상자와 설계 상자의 정확한 다면체 교집합을 쓴다. 벽돌 자세는 시뮬레이터 참값이다(채점 전용). 이 부분 코드는 10-15 이후 바뀌지 않았다(`git log`). 그래서 10월과 11월 결과의 정의가 같다 |
| 빈 자리 | IoU = 0. 18개 조건 모두에서 빈 자리의 저장값이 0인 것을 확인했다 |
| IoU 평균 | 1600자리 평균(빈 자리 0) |
| IoU 중앙값 | 채운 자리만 |
| 통과 벽돌 | 채운 자리 중 IoU ≥ 기준. 반장 자리는 벽마다 2곳이다(자리 5 · 10, 100벽에 200자리) |
| 기준 A (하한) | 온장 ≥ 0.749, 반장 ≥ 0.702 |
| 기준 B (상한) | 온장 ≥ 0.959, 반장 ≥ 0.953 |
| 참고 | 모두 ≥ 0.875 |
| 대응 차이 | 같은 시작값의 벽끼리 뺀 값. 구간은 벽 단위 부트스트랩 95 %(10000번, 시드 0)다. 통과 수 차이는 100벽 합으로 적었다(벽당 평균의 구간 × 100) |
| 비교 기준 | 설계 단계는 직전 단계, 역방향 제거는 ⑤ Full. 오차 부여는 '오차 없음' 대비를 참고로 더했다(지시에 없던 것) |

기준 값 확인 (설계 상자를 평행 이동해 잰 IoU, 계산은 `threshold_check()`):

| 이동 (x · y · z mm) | 온장 | 반장 |
|---|---|---|
| 6 · 6 · 3 | 0.7487 | 0.7025 |
| 0 · 6 · 0 | 0.875 | 0.875 |
| 6 · 0 · 0 | 0.9388 | 0.875 |
| 0 · 0 · 3 | 0.900 | 0.900 |

- 기준 A는 'x · y 6 mm, z 3 mm를 한꺼번에 옮긴 상자'의 IoU를 셋째 자리에서 반올림한 값과 맞는다. 다만 정확히 그만큼 옮긴 온장은 0.7487이라 0.749에 조금 못 미친다.
- 참고 기준 0.875는 벽 두께 방향(y)으로 6 mm만 옮긴 값과 같다.
- 기준 B 값의 근거는 이번에 확인하지 않았다.
