저장소 sim/ 폴더에서 다음만 한다. 시뮬레이션은 돌리지 않는다(집계만, 1~2분). 기존 파일은 수정하지 않는다.

1. 최신 코드 받기: `git pull --ff-only` 후 `ls sim/tools/paired_noise_table.py` 확인.
2. 실행: `cd sim && venv/bin/python tools/paired_noise_table.py`
   - `tools/paper_results.py` 와 같은 방식(최종 JSON + 마감 시 끊긴 실행의 로그 줄)으로 기존 조건 D 시험 결과를 모으고, 7쪽과 같은 배치에서 σ 0/2/4 mm 완성 수를 낸다.
   - 표의 σ 0 mm 가 Diffusion 30/40, ACT 26/48 로 나와야 한다. 다르면 그대로 두고 이유(어떤 파일·로그가 빠졌는지)를 보고한다.
   - 오류가 나면(예: paper_results.py 의 SIM 경로가 이 PC와 다름) 우회하지 말고 오류 원문을 보고한다.
3. 결과 올리기 (저장소 최상위에서):
   ```bash
   D=01_사기설/중간발표1/근거_우분투_20261012
   cp sim/outputs/midterm1_fix/paired_noise.md sim/outputs/midterm1_fix/paired_noise.json "$D"/
   git add "$D"/paired_noise.md "$D"/paired_noise.json
   git commit -m "측정 오차 결과를 7쪽과 같은 배치로 재집계 (paired_noise)"
   git pull --rebase && git push
   ```
4. 보고: `paired_noise.md` 표 전체와 커밋 해시.
