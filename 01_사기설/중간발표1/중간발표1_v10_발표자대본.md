# 중간발표 1 발표자 대본 (v10 슬라이드 기준)

발표자: 정성용 · 슬라이드 `중간발표1_v10_20261011.pptx` · 각 쪽마다 무엇을 강조할지 정리

**가장 중요한 쪽: 2쪽(연구 개요), 6·7쪽(핵심 결과).** 시간이 모자라면 5·11쪽을 줄인다.

## 먼저 알아둘 용어

| 용어 | 뜻 |
|---|---|
| 정책 | 카메라 영상과 관절값을 보고 다음 관절 동작을 내는 학습 모델 (ACT, Diffusion Policy) |
| 역기구학 대본 | 벽돌 좌표를 아는 프로그램이 자동으로 만든 시연. 학습 데이터 생성용 |
| 검사 3단계 | 정책 밖에 붙인 규칙: 잡기 확인 → 놓기 전 보정 → 놓은 뒤 재배치 |
| 정답 좌표 | 시뮬레이터가 아는 벽돌의 실제 위치. 원래 채점용. 실험 3 검사에 쓴 것이 교수님 지적 대상 |
| 완성률 | 벽돌 3개 모두 허용오차(위치 4.5 mm·높이 4.5 mm·방향 5°·기울기 10°) 안에 놓인 시행 비율 |
| 초기 배치 | 벽돌이 처음 놓인 위치·방향. 좁음 ±5 mm / 넓음 ±30 mm·±60° |
| 학습 seed | 같은 데이터로 학습을 다시 돌릴 때의 난수 시작값. 3번 학습해 우연이 아님을 확인 |

## 슬라이드별

**1쪽 · 표지**
- 인사, 14조 소개, 발표자 본인
- 제목 풀기: 학습 로봇이 실패를 다루는 방식의 딜레마, 그리고 그것을 정책 밖 검사로 푼 설계
- 강조: **모든 실험은 MuJoCo 시뮬레이션** (실물 로봇 아님)
- 과제: 소형 팔 SO-ARM101로 축소 벽돌 3개를 2+1(아래 2개, 위 1개)로 쌓기
- 사진: 모르타르층 위에 세 번째 벽돌을 놓는 장면

**2쪽 · 연구 개요 (가장 중요)**
- 배경: 기존 조적 로봇은 레이저 트래커 같은 **외부 계측 장비**로 벽돌마다 위치를 다시 맞춤 → 조건이 바뀌면 사람이 재설정
- 모방학습: 시연을 보고 **카메라·관절값만으로** 동작 → 재설정 부담 없음
- 문제(핵심): 성공 시연만 배워서 **실패 상황을 못 다룸**
- 딜레마(오른쪽 빨간 두 칸 가리키기): 복구를 가르치면 정상일 때도 더듬거려 **정밀도 손실** / 안 가르치면 헛집어도 **모르고 진행**
- 해법(파란 칸): **정책은 그대로**, 실패 확인·보정은 **정책 밖 검사**에 맡김
- 목적: 그 검사의 효과, 필요한 정보와 정확도, 외부 계측 없이 카메라로 되는지
- 기여 4개는 읽고 넘어감 → "근거는 뒤에서 보여드림"

**3쪽 · 설계수행계획서 대비 수정 사항 및 진행상황**
- 구조 먼저: 왼쪽 = 계획 대비 바뀐 것, 오른쪽 = 진행 상황
- 가장 큰 변경: 시연을 사람 원격조작 대신 **역기구학 대본**으로 자동 수집 (영상 재생)
- 역기구학 한 줄: 목표 위치를 주면 **관절 각도를 거꾸로 계산** → 벽돌 좌표로 집기·놓기 경로 자동 생성
- 바꾼 이유 3개: 숙련자 불필요, 사람마다 습관 차이 없음, 성공 자동 판정 (**454번 중 240개 채택**)
- 정책: 4종 동시 비교 → ACT·Diffusion 우선. **SmolVLA·π0.5는 버린 것 아님, 추후 비교**
- 실패 대응: 원래 11월 계획인 검사 3단계를 실험 2 실패를 보고 **앞당겨 구현**
- 오른쪽: 계획서 완료 기준 5개 **모두 달성**, 카메라 검측(10/8~)만 진행 중

**4쪽 · 연구 질문과 대응 실험**
- 연구 질문 5개를 한 줄씩: 복구 학습의 득실 → 정책 밖 검사 효과 → 필요한 정보·정확도 → 카메라로 대체 → 벽체 규모
- 상태: 1~3 완료, 4 진행 중, 5 최종 발표
- 아래 화살표 = 실험 3 설계: 같은 정책에 검사를 **하나씩 추가** A → B → C → D
- A 정책만 / B 집게로 잡혔는지 확인 / C 놓기 직전 위치 보정 / D 놓은 뒤 틀렸으면 한 번 다시 놓기
- 핵심 논리: 정책은 같고 초기 배치도 같음 → **완성률 차이 = 검사의 효과**
- 질문 대비: 완성률 기준 = 벽돌 3개 모두 위치 4.5 mm·높이 4.5 mm·방향 5°·기울기 10° 이내

**5쪽 · 방법론 근거**
- 시작 멘트: 교수님 피드백 "**모든 선택에 이유**"에 대한 답
- 모방학습: 보상 함수 설계 불필요 (강화학습은 '무엇이 잘한 것인지'를 수식으로 정해야 함)
- 시뮬레이션: 같은 배치를 수백 번 반복, 실패를 그대로 재현 → 원인 분리
- 역기구학 대본: 3쪽과 같은 이유
- 검사는 정책 밖: 복구를 정책에 가르치면 정밀도가 떨어짐(6쪽 영상), 정책 고정 → 검사 효과만 측정
- 정답 좌표로 먼저 시험: 영상 기반 시험 전에 **"위치를 완벽히 알 때"의 기준선** 측정 → 그다음 카메라로 교체(8쪽)
- 질문 대비: 왜 ACT·Diffusion? 영상→관절 모방학습의 대표 두 계열, 공개 구현(LeRobot)으로 재현 가능

**6쪽 · 핵심 결과 ① 영상 (가장 중요)**
- 순서: 좌상 → 우상 → 좌하 → 우하
- 좌상 ACT: 좁은 배치(±5 mm)는 3개 완성, 넓은 배치(±30 mm·±60°)는 헛집고 멈춤 → **63% → 0%**
- 우상 Diffusion: 넓은 배치에서도 성공하는 경우가 있지만 **21%** (200번 중 41번)
- 좌하: 집지 못했는데 그대로 벽까지 운반 → **딜레마 ①: 복구를 안 가르치면 실패를 모름**
- 우하: 복구 시연을 섞어 학습한 Diffusion → 3개 다 놓고도 계속 더듬거림 → **딜레마 ②**
- 결론: 두 방향 모두 문제 → 그래서 **정책 밖 검사** (7쪽으로 연결)
- 질문 대비: 좌하는 실험 2에서 관찰된 빈손 운반 유형을 재현한 장면 / 우하는 실험 1(좁은 배치) 조건, 복구 시연을 섞자 완성률 90% → 33% 이하

**7쪽 · 핵심 결과 ② 검사 효과 (가장 중요)**
- 결론 먼저: 정책을 다시 학습하지 않고 **검사만 더해 완성률 2배 이상**
- 큰 숫자: Diffusion **35% → 75%**, ACT **0% → 54%**
- 그래프 A→D: B(잡기 확인)는 거의 변화 없음 → 빈손은 막아도 **어디로 가야 할지 모름**
- C(놓기 전 보정)에서 급상승 → 효과는 **놓는 순간**에서 나옴
- 표 '현장' 열: A·B는 지금도 현장에서 가능, C·D는 **벽돌 위치를 알아야 함** → 실험 3에서는 시뮬레이터 정답 좌표를 씀
- 의미: "위치 정보가 있으면 이만큼 오른다"는 기준선 → 카메라로 바꾼 결과는 8쪽
- 질문 대비: 학습 seed 1000 모델, 같은 시험 배치(Diffusion 40회·ACT 48회). seed 3개를 합쳐도 같은 경향(28→63%, 0→60%)

**8쪽 · 보조 검증: 위치 정확도와 카메라**
- 질문으로 시작: "위치는 얼마나 정확해야 하고, 카메라로 그게 되나?"
- ① 검사가 읽는 벽돌 위치에 **일부러 무작위 오차** 주입 → 로봇은 틀린 위치로 보정, 채점은 실제 위치로
- 2 mm만 틀려도 ACT 60→30%, Diffusion 85→63% → **위치는 2 mm보다 정확해야 함**
- ② **작업대 위 고정 카메라 1대**(컬러+깊이)로 벽돌 위치 계산, 정답 좌표 안 씀 (노랑 = 추정 윤곽, 빨강 = 실제 중심)
- 1,963번 추정 중 **95%가 1 mm 이내** (평균 0.43 mm) → 2 mm 기준 충족
- ③ 검사에 카메라 추정값을 넣어도 완성 횟수가 정답 좌표와 **2~3회 차이** (38→35, 48→45)
- 주의: ③은 **역기구학 대본 + 검사** 결과. 학습 정책 + 카메라는 지금 평가 중
- 질문 대비: 시뮬레이션 렌더라 잡음·흐림이 없어 실제 카메라보다 낙관적일 수 있음

**9쪽 · 실제 적용 현장과의 차이와 현재 한계**
- 시작 멘트: 교수님 피드백 "**실제 적용 현장과 차이점 도출**"에 대한 답
- 가장 큰 차이 = **위치를 어떻게 아는가**: 실험 3은 정답 좌표 → 작업대 카메라로 교체 중(8쪽)
- 모르타르: 일정 두께 층 + 2초 뒤 고정으로 단순화, 부착·경화는 미구현 → 모든 조건에 같은 단순화라 **비교는 공정**
- 규모: 축소 벽돌 3개·소형 팔 → 실척 벽체·산업용 팔로 확장 예정(10쪽)
- 센서·자재: 잡음 없는 센서, 같은 치수 벽돌 → 잡음 민감도·치수 편차 실험으로 영향 확인
- 한계 1: 정책 단독 완성률이 낮음 → 검사 3단계로 보완
- 한계 2: **학습 정책 + 카메라 결과는 아직 없음** → 중간발표 2에서 제시

**10쪽 · 향후 계획**
- 간트 읽는 법: 파랑 P1 = 중간발표 2 전 필수, 회색 P2 = 최종까지, P3 = 여유 있을 때
- P1: 카메라 검측 + 학습 정책 평가(~10/24), 대형 환경 구축 병행(~11/3)
- 카메라 검측 다시 한 줄: 정답 좌표 대신 **작업대 카메라 영상**으로 벽돌 위치를 추정해 검사에 사용
- P2: 시연 수 곡선(60/120/240개로 학습해 데이터 양의 효과 확인), 벽체 학습·평가(11/11~12/1)
- 오른쪽 그림: 대형 환경 콘셉트 — UR5e 산업용 팔, 실척 벽돌(190×90×57 mm), 3단 벽체
- 마무리: 핵심 한 줄("정책은 그대로, 검사는 정책 밖, 위치는 카메라로") + 감사 인사

**11쪽 · 부록 (질문 때만)**
- 발표 때는 넘기고, 재현성·설정 질문이 나오면 이 쪽을 펼침
- 4.5 mm 근거: 실척 허용오차 9.5 mm(세로줄눈 TMS 402/602, 벽면 직진도 LABC)를 벽돌 축소비(약 0.47배)로 환산한 팀 설정
- 데이터: 시연 240개(학습 200, 검증 40), 학습 seed 3개
- 검사 문턱: 잡기 = 집게 각도 0.2 rad 이상 + 하중 0.9 N 이상 / 보정 = 2.5 mm 넘으면 / 재배치 = 4.5 mm 넘으면
