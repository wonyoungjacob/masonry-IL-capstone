# 실험 1·2 실패 원인 문헌 검토 및 다음 진단

작성: 2026-09-22. 기존 코드·로그·데이터셋 메타데이터와 아래 원문 논문을 대조함. 학습·정책 평가를 재개하지 않았음. 문헌의 결과, 우리 실험의 관측, 아직 검증하지 않은 가설을 구분함.

## 팀원 공유용 문제 요약

- 목표: 다양한 초기 블록 배치에서 3개 블록을 2+1 형태로 조적. 각 블록의 첫 파지 성공 및 그리퍼 해제 이후 재조정 금지.
- 데이터 수집: 454회 시도 중 240회 채택, 214회 폐기. 파지 검사 실패 139회로, 수집 전문가의 실행 가능성과 판정 정확성 점검 필요.
- 학습 결과: 실험 2 완료 시험에서 ACT 0/300, Diffusion 41/200, SmolVLA 0/200. 성공 시연 확보가 정책의 실제 수행 성공으로 이어지지 않는 상태.
- 원인 분리 문제: 초기 배치 범위, 데이터 선별, 카메라, 행동 실행 길이 등이 함께 변경되어 성능 저하의 단일 원인을 특정하기 어려움.
- 우선 조사: ① 파지·배치 전문가와 성공 판정 ② ACT 학습·실행 일치 및 단계별 실패 ③ 성공 시연의 상태 범위와 해제 전 정밀 배치.
- 에피소드 길이: 실험 1 clean과 실험 2의 저장 시연은 모두 18.3초. 단순 길이보다 초기 실패와 연속 작업 중 오차 누적을 구분할 필요.

## 1. 에피소드당 수집 시간이 긴 것이 원인인가?

**현재 증거로는 18.3초라는 길이 자체를 실험 2 성능 급락의 주원인으로 보기 어려움. 연속 작업 중 오차 누적은 유효한 별도 가설임.**

| 구분 | 실험 1 clean | 실험 2 |
|---|---:|---:|
| 채택 시연 수 | 119 | 240: 학습 200, 검증 40 |
| 저장 시연 길이 | 전부 366프레임 | 전부 366프레임 |
| 제어·기록 주파수 | 20 Hz | 20 Hz |
| 저장 시연 시간 | 18.3초 | 18.3초 |
| ACT 예측 길이 | 100스텝, 5초 | 100스텝, 5초 |
| ACT 한 번 예측 후 실행 길이 | 100스텝, 5초 | 10스텝, 0.5초 |
| ACT temporal ensemble | 미사용 | 미사용 |
| ACT 전체 완성 성공 | 63/100 | 0/300 |

마지막 행은 초기 상태 등 다른 조건도 달라진 결과이며, 실행 길이의 인과 효과를 뜻하지 않음. 90초는 정책 평가의 최대 동작 시간이며 학습 시연 길이가 아님. 이후 2.5초 정착 평가가 추가됨. 렌더링 때문에 컴퓨터에서 수집 완료까지 오래 걸리는 시간도 시뮬레이션 속 동작 시간과 구별해야 함.

ACT 원문 §V-B의 실제 로봇 시연은 50 Hz에서 400~700스텝, 약 8~14초임. 우리 366스텝은 이보다 많지 않으며, 로봇·과제·주파수가 달라 초 단위만으로 학습 한계를 정할 수 없음. [ACT 원문](https://tonyzhaozh.github.io/aloha/aloha.pdf)

수집 로그의 파지 검사 실패 139회를 작업 순서로 분류하면 첫 블록 70회(t=50, 2.5초), 둘째 블록 7회(t=172, 8.6초), 셋째 블록 62회(t=294, 14.7초)임. 이는 각 단계에 도달한 횟수로 나눈 조건부 실패율이 아니며, 블록 ID와 집는 순서도 구별해야 함. 적어도 70회는 긴 후반부 작업 이전의 실패임. 이것은 전문가 수집에 관한 관측이며 ACT 실패 원인을 직접 증명하지 않음.

DAgger가 다룬 문제는 정책의 작은 행동 오차로 다음 관측이 시연에서 멀어지고 이후 오차가 커지는 현상임. 검증할 가설은 ‘영상이 길어서 안 된다’보다 ‘세 번의 집기·배치에서 앞 단계의 오차가 뒷 단계의 입력을 바꾼다’가 적합함. [DAgger §2–3](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)

단순히 366프레임 파일을 세 개의 122프레임 파일로 잘라도 ACT는 원래 짧은 행동 구간을 표본 추출해 학습하므로 문제가 자동 해결되지 않음. 경계의 패딩과 표본 분포는 바뀌지만, 어떤 블록을 어느 목표에 놓아야 하는지 식별하는 문제는 남음. 단계 분할을 택한다면 목표·단계 정보와 전환 조건까지 설계해야 함. 자유 이동은 경유점, 접촉 작업은 촘촘한 제어로 나누는 HYDRA가 관련 참고이며, 단순 영상 분할의 효과를 증명한 논문은 아님. [HYDRA §4](https://proceedings.mlr.press/v229/belkhale23a/belkhale23a.pdf)

## 2. 담당 1: 잘 집는 시연을 어떻게 수집·검증해야 하는가?

### 파지 자세와 접근 경로

현재 초기 배치 검사는 블록 간 겹침, 벽과의 간격, 중심의 작업 반경 등을 확인하지만 열린 그리퍼 전체의 이동 공간과 전 구간의 관절 도달 가능성을 보장하지 않음. 무작위 배치 확대 시 기존 전문가의 고정 접근 방식이 실패할 수 있다는 가설이 우선임.

우리 전문가 개선 제안: 물체 중심뿐 아니라 양쪽 접촉 위치, 접근 방향, 열린 손가락과 주변 블록의 충돌, 접근·상승 중 IK 가능성을 검사. 현재 시뮬레이터가 제공하는 정확한 기하 정보로 먼저 수집기를 검증할 수 있음. Contact-GraspNet은 접촉 기반 파지 후보와 비충돌 파지 조건을 다루지만, 6-DoF 파지 후보가 우리 5관절 팔에서 그대로 실행 가능하다는 뜻은 아님. [Contact-GraspNet §III, §IV-B–C](https://arxiv.org/pdf/2103.14127)

### 실제 파지 성공 판정

손가락을 닫으라는 명령과 물체를 실제 잡았다는 관측을 구별해야 함. 현재 수집기는 15 mm 상승과 양쪽 손가락 접촉을 검사하므로 파지 검사가 아예 없는 것은 아님. 접촉의 순간 변동이나 주변 블록에 걸친 상태를 구별하는 정확도가 추가 검증 대상임.

제안: 양쪽 접촉, 물체 높이 증가, 손과 물체의 상대 자세 유지, 운반 중 동반 이동을 일정 구간 함께 확인. 길이는 우리 접촉 동역학과 수동 판독 결과로 정해야 함. Calandra 등의 연구는 들어 올린 뒤 유지하는 구간과 촉각 접촉 판정을 사용하고 애매한 표본을 수동 확인함. 이 연구의 센서와 4초 유지 시간을 그대로 이식할 필요는 없음. [More Than a Feeling §V](https://www.seas.upenn.edu/~dineshj/publication/calandra-2018-more/calandra-2018-more.pdf)

### 실패 데이터는 버려야 하는가?

모방학습용 성공 시연에서는 제외하되 실패 초기 배치·이유·접촉·영상을 진단 기록으로 유지할 가치가 있음. 실패 행동을 정답으로 학습하는 것과, 실패한 상태에서 전문가의 올바른 행동을 새로 확보하는 것은 다름. 후자는 DAgger의 취지와 연결되지만 첫 파지 성공·해제 후 재조정 금지 조건을 유지하도록 수집 범위를 제한해야 함.

수집 성공률 자체로 학습 결과를 예측해서도 안 됨. MimicGen은 성공한 생성 시연만 보존하며, 생성 성공률이 낮아도 학습한 정책의 성공률이 높은 사례를 보고함. 수집기의 문제와 채택된 데이터의 학습 가능성은 따로 평가해야 함. [MimicGen §4, §5의 generation success rate 논의 및 Appendix P](https://arxiv.org/pdf/2310.17596)

## 3. 담당 2: ACT는 왜 손실이 낮아도 실행에 실패하는가?

### 행동 묶음, 실행 길이, temporal ensemble

| 개념 | 역할 | 이번 실험 해석 |
|---|---|---|
| 행동 묶음 예측 | 한 관측에서 연속된 행동을 예측해 동작의 일관성과 진행을 학습 | 100스텝 예측 유지 |
| 재관측 전 실행 길이 | 예측 중 몇 스텝을 실행한 뒤 새 관측으로 다시 예측할지 결정 | 100→10스텝 변경 |
| Temporal ensemble | 서로 다른 시점의 예측들이 같은 실행 시점에 제안한 행동을 결합 | 두 실험 모두 미사용 |

ACT §VI-A는 서로 다른 chunk 크기로 각각 재학습한 실험에서 중간 길이의 묶음이 유효하며 지나치게 긴 묶음에는 반응성 저하가 있음을 보여 줌. **고정 chunk=100에서 실행 길이만 100→10으로 바꾼 우리 설정과 동일한 실험이 아님.** 따라서 짧은 재계획 때문에 동작이 정체된다는 것은 검증할 가설이지 확정 원인이 아님. [ACT §IV-A, §VI-A](https://tonyzhaozh.github.io/aloha/aloha.pdf)

Diffusion Policy 역시 연속 행동의 일관성과 관측에 대한 빠른 반응 사이의 절충을 보고함. 논문의 특정 최적 스텝 수를 로봇과 제어 주파수가 다른 우리 실험의 정답으로 가져올 수는 없음. [Diffusion Policy §5.3, Fig. 5](https://diffusion-policy.cs.columbia.edu/diffusion_policy_ijrr.pdf)

### 낮은 검증 손실과 낮은 성공률이 공존하는 이유

저장된 성공 시연의 관측에서 정답 행동을 맞히는 평가와, 정책이 스스로 만든 상태를 다시 보며 작업을 끝내는 평가는 다름. 파지·해제 순간의 작은 오차가 중요한데 전체 평균 손실에서는 잘 드러나지 않을 수 있음. Robomimic 연구는 최저 검증 손실 또는 최종 체크포인트 선택이 높은 실행 성공률을 보장하지 않음을 실험적으로 보임. [What Matters §4.5, Fig. 5](https://proceedings.mlr.press/v164/mandlekar22a/mandlekar22a.pdf)

우리 코드에서 정규화 누락이 현재 확인된 것은 아님. 다음을 검사할 이유는 과거 유사 오류 이력과 증상 때문이며, 재발했다고 단정하면 안 됨: 이미지 채널·크기·범위, 관절 순서와 단위, 절대 목표 관절각/증분 구분, 정규화·역정규화, 관측과 행동의 시간 정렬, 실제 제어 주기.

학습량도 분리 필요: ACT는 같은 40,000 업데이트·배치 32라도 학습 데이터가 119개에서 200개로 늘었으므로 프레임당 명목 노출이 약 29.4회에서 17.5회로 감소함. ‘너무 길어서’와 다른 가설이며, 이 수치만으로 학습 부족을 확정할 수 없음.

## 4. 담당 3: 성공 시연만으로 일반화와 첫 배치 정확도를 얻을 수 있는가?

### 성공 시연만 쓰는 설계

가능한 접근임. ACT의 시뮬레이션 실험과 MimicGen에도 성공 시연을 사용하는 설정이 있음. 다만 성공만 남기는 과정에서 어려운 초기 배치가 과도하게 제거되면, 무작위로 생성한 분포와 실제 학습 데이터의 분포가 달라질 수 있음. 우리 데이터에 그 편향이 어느 정도인지 위치·각도·간격별 채택률로 확인해야 함. 무작위화 확대 자체가 일반화 개선을 보장하지 않음. [MimicGen §4–5](https://arxiv.org/pdf/2310.17596)

### 초기 무작위화와 보정 상태는 다름

초기 위치를 바꿔 완벽하게 수행하는 시연과, 운반 중 손 안에서 블록이 조금 돌아간 상태에서 해제 전 정렬하는 시연은 서로 다른 상태를 다룸. DAgger는 정책이 방문한 상태에 전문가 행동을 붙이며, DART는 전문가 행동에 조절된 잡음을 넣어 오차 주변의 보정 동작을 수집함. 단순 초기 배치 무작위화나 블록에 임의 충격을 가하는 것만으로 같은 방법을 구현했다고 할 수 없음. [DAgger](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf), [DART §4](https://proceedings.mlr.press/v78/laskey17a/laskey17a.pdf)

### 보정의 허용 범위

| 시점 | 이번 목표에 맞는 처리 |
|---|---|
| 집기 전 | 한 번에 잡을 수 있도록 손의 접근·정렬 보정 가능 |
| 집은 뒤 운반 중 | 블록을 계속 잡은 상태의 위치·방향 보정 가능 |
| 내려놓기 직전, 해제 전 | 목표와의 오차를 줄이고 지지 상태 확인 |
| 그리퍼 해제 후 | 다시 집기·밀기·재정렬 금지. 해당 블록 배치를 완료 또는 실패로 판정 |

일반 모방학습 문헌의 보정 데이터 효과를 ‘모르타르 위에 해제한 블록을 다시 집는 과정이 필요하다’로 해석할 근거는 없음. 이번에 읽은 논문들은 그 재료·공정 제약을 직접 비교한 실험이 아님.

### 처음부터 정확하게 놓기

물체와 목표 사이의 위치·방향 오차를 관측하여 해제 전 줄이는 폐루프 제어가 적합한 방향임. Visual servoing 문헌은 영상 또는 추정 자세의 목표 오차를 이용하는 제어를 정식화함. [Chaumette & Hutchinson, Visual Servo Control Part I](https://web.mit.edu/amcp/OldFiles/drg/Chaumette_Part_I.pdf)

단, 우리 전문가에는 이미 실제 블록 좌표를 이용한 해제 전 보정이 있음. 정책은 영상·관절 상태에서 이를 배워야 하므로, 전문가가 쓰는 정밀 정보가 정책의 입력에서 충분히 식별되는지와 접촉 후 자세 변화가 핵심 점검 대상임. ‘보정 제어를 추가하면 해결’이라고 단정할 수 없음.

또한 중간 배치 검사의 xy 허용오차 8 mm와 최종 성공 기준 4.5 mm가 다름. 최종 검사만 실패한 38회를 분석하고, 전문가가 해제해도 좋다고 판단하는 기준을 최종 품질 기준과 연결할 필요가 있음. 해제 전 오차가 작아도 손을 연 뒤 가라앉거나 기울 수 있어 해제 후 결과 관측은 필요함. 이 관측은 재조정 행동을 뜻하지 않음.

깨끗한 시연만 학습했다고 배포 정책의 재조정 금지가 보장되지는 않음. 현재 정책 평가에는 이를 강제로 막는 장치가 없음. 향후 제약을 강제한다면 정책 단독과 제약 제어기를 포함한 시스템의 성능을 구별해 보고해야 함.

### 데이터와 지표 구성

학습 데이터는 하나로 유지하고 초기 배치, 대상 블록, 동작 단계, 파지 확인, 해제 시점 등의 메타데이터를 붙이면 됨. 학습/검증/시험 분리는 실험군을 여러 개 만드는 것과 다름. 명확한 가설이 생겼을 때에만 이진 비교를 추가.

권장 지표: 첫 시도 파지 성공률, 파지 후 운반 유지율, 첫 해제 후 배치 정확도, 해제 후 재접촉·재조정 위반율, 3개 전체 완성률, 단계별 시간과 최초 실패 시점. 단계별 비율은 해당 단계까지 도달한 시행을 분모로 사용하고 전체 완성률과 함께 보고.

## 5. 재학습 전에 할 진단은 세 가지로 제한

아래는 제안이며 이번 문헌 조사 중 실행하지 않았음. 기존 체크포인트, 별도 검증 초기 상태, 동일한 조건을 사용하고 기존 시험 세트를 반복 튜닝에 사용하지 않는 것이 원칙.

1. **데이터·실행 연결 검증:** 기록된 성공 행동을 같은 초기 상태에서 재생하고, 저장 관측과 실시간 입력 및 정규화 전후 행동을 대조. 이어서 전문가 관측에서 정책이 파지·해제 구간을 예측하는 오차 확인. 기록 재생 자체가 실패하면 모델 비교보다 데이터·제어 연결부터 해결.
2. **ACT 실행 길이 비교:** 동일한 기존 ACT 체크포인트에서 n_action_steps=10과 100만 비교. 파지 시점, 정체 시간, 첫 배치, 전체 완성률을 같은 초기 상태에서 측정. 이 비교는 학습 변경 없이 실행 설정 가설을 점검함. Temporal ensemble을 동시에 바꾸면 원인이 섞이므로 별도 후속 후보로 유지.
3. **연속 작업 오차 누적 진단:** 기존 시연을 물리적으로 재생하여 각 블록 작업 시작 상태를 만든 뒤 정책에 넘겨 남은 작업을 평가. 처음부터 정책이 수행한 경우와 비교하되 단계별 정상 상태에서의 성공은 별도 진단값으로 표시. ACT 내부 행동 큐를 초기화하고, 회복되면 앞 단계 오차 누적 가설, 회복되지 않으면 해당 단계 자체의 인식·행동 학습 문제를 우선 검토. 초기 단계 실패와 90초 평가 중 완성 후 재접촉도 별도 기록.
