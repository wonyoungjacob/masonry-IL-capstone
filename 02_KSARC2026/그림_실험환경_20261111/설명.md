# 실험 환경 그림: 로봇 팔 · 카메라 · 벽돌 (설명용, 결과 아님)

> 2026-11-11. 그림: [`실험환경_로봇_카메라_벽돌.png`](실험환경_로봇_카메라_벽돌.png). 스크립트: `sim/wall3/fig_env_scene_20261111.py` (커밋 9e1c05df 다음에 만듦).
> 포스터 3.1절 '실험 환경 세팅'에 쓴다. 숫자 결과가 아니라 장면 설명이다.

## 사실

| 항목 | 값 |
|---|---|
| 환경 설정 | `scene_config("main_v1_eval")` (평가와 같음). 화면 밖 렌더 크기만 2400 × 1800으로 키움(물리 · 카메라는 그대로) |
| 장면 | 시연기 `WallExpert`를 시작값 700300으로 돌려 9번째 벽돌을 자리 위에서 내리기 시작한 순간 (`place_descend`, 환경 스텝 1510) |
| 벽돌 | 벽에 8장 · 집게에 1장 · 공급대에 7장 |
| 보는 방향 | 자유 카메라: 방위 -38.0° · 높이각 -14.0° · 거리 3.4 m · 중심 (0.12, 0.42, 0.88) |
| 정면 카메라 | 위치 [0.0, 1.75, 0.75] m · 세로 시야각 50° · 정책 입력 |
| 작업대 카메라 (위) | 위치 [0.0, 0.6, 1.85] m · 세로 시야각 45° · 정책 입력 + 검측 G2 · G3(1280 × 960 색 + 깊이) |
| 손목 카메라 | 집게에 붙음 · 세로 시야각 80° · 정책 입력 |
| 오른쪽 세 장 | 같은 순간 세 카메라의 시야를 512 × 512 화소로 그린 것. 정책 입력은 같은 카메라의 128 × 128 영상 |

## 그림에만 있는 것 (실험 장면에는 없음)

- **카메라 표식**: 시뮬레이터의 카메라는 몸체가 없는 점이다. 정면 · 작업대 카메라 자리에 상자 + 파란 렌즈 + 짧은 시야 모서리(0.42 m) + 시선(카메라에서 보는 점까지 가는 선)을 그려 넣었다. 크기는 보이도록 키운 것이고 실제 카메라 크기가 아니다. 표식은 그림자를 드리우지 않게 했다.
- **흰 배경**: 시뮬레이터 배경은 검정이라, 멀리 흰 판을 두어 흰색으로 바꿨다.
- **이름표와 이음선**: matplotlib으로 얹었다.

## 주의

- 이 장면은 **시연기**(참값을 쓰는 시연 생성기)가 만든 것이다. 학습 정책 + 검측(Full)이 만든 장면이 아니다. 환경 구성만 보이는 용도다.
- 검측 G0 · G1 · H는 카메라를 쓰지 않는다(도면 · 관절값 · 손목 힘 · 집게 각도). 포스터 2절 표와 같다.
