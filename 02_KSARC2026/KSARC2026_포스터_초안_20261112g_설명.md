# KSARC 2026 포스터 g판 설명 (2026-11-12, 윈도우)

f판과 같은 양식에서 문장 문체와 학회 양식 파일 규칙(제목 · 저자 · 그림/표 제목)만 고친 판. 실험 숫자 · 내용 · 절 순서는 f판과 같음.

- 파일: [KSARC2026_포스터_초안_20261112g.pptx](KSARC2026_포스터_초안_20261112g.pptx), [PowerPoint 그림](포스터_초안_20261112g_PowerPoint.png), [배치 · 바꾼 문장 기록](포스터_초안_20261112g_배치.json), 그림 폴더 `포스터_초안_20261112g_그림/`
- 스크립트: `sim/wall3/poster_rewrite_ksarc_20261112g.py` (윈도우 + PowerPoint 필요, f판 스크립트의 restyle · layout 사용)

## 1. 사용자 지시 (11-12)

| 지시 | 반영 |
|---|---|
| "내용은 좋은데 말투가 처참할 정도로 클로드 냄새가 난다" (예: "이렇게는 알 수 없는 것:", "(효과 없음이 아님)") | 본문 · 표 · 그림 글을 레퍼런스 포스터(ksarc_포스터_v12.pdf) 문체로: 개조식 "~함 / ~임", "• 머리말: 내용" |
| "기본 pptx에 양식 적혀 있잖아. 그림 표나 첫 대제목 양식" | 학회 양식 파일(ksarc-포스터 PPT 양식.pptx)에 적힌 규칙 적용 (2절) |

## 2. 학회 양식 파일 규칙 적용

| 양식 파일에 적힌 것 | f판 | g판 |
|---|---|---|
| 국문 제목 48 pt 굵게, 영문 제목 40 pt, 가운데 | 국문 44 pt + 부제 30 pt 따로 | 국문 48 pt. 부제는 콜론으로 붙이고 로고와 겹치지 않게 콜론 뒤 줄바꿈 (영문 제목과 같은 구조) |
| 저자 "홍길동*, 홍길서**" 32 pt, 영문 이름 32 pt | "정원영¹ • …", 영문 22 pt | "정원영*, 강현준*, 김홍조*", 영문 "Jung, Wonyoung, Kang, Hyunjoon, Kim, Hongjo" 32 pt |
| 소속 "*ㅇㅇ대학교 …" 한 줄 | 3줄 (회원 구분 · 과정 · 이메일 · 교신저자) | "*연세대학교 건설환경공학과" 한 줄 (세 사람 소속이 같아 별표 하나, 레퍼런스 포스터와 같은 방식) |
| 표 제목은 표 위 왼쪽 정렬 | 결과 표만 제목 | 표 1 · 2 · 3 모두 "표 n. 제목", 표 위 왼쪽 |
| 그림 제목은 그림 아래 가운데 정렬 | 없음 | 그림 1 ~ 6 모두 "그림 n. 제목", 그림 아래 가운데 |
| 내용 구성 · 글꼴 · 크기는 자유 | – | 맑은 고딕 + Calibri, f판 크기 비율 그대로 |

그림 · 표 제목:

| 번호 | 제목 |
|---|---|
| 그림 1 | 정책 단독과 검측 6단계 적용(Full)의 완성률 |
| 그림 2 | 벽돌 1장의 작업 순서와 검측 단계 |
| 그림 3 | 실험 환경과 카메라 시야 (카메라 형상은 위치 표시용이며, 시뮬레이터 내 카메라는 형상 없음) |
| 그림 4 | 평가 기준: 자리 채움 → 벽 완성 → 시방 합격 |
| 그림 5 | 조건별 자리 채움 벽 수 (조건별 100벽) |
| 그림 6 | Full과 Full – G3의 시방 항목 측정값 |
| 표 1 | 검측 단계별 기능과 사용 정보 |
| 표 2 | 연구 질문과 판정 기준 |
| 표 3 | 검측 단계 제거에 따른 완성 벽 수 차이와 신뢰구간 (동일 100벽 비교) (f판의 표 1) |

## 3. 문체 바꾼 예

전체 전후 대조는 배치 json의 "바꾼 문장" 항목에 있음.

| f판 | g판 |
|---|---|
| … 전체 성공률만 보고했다. 이렇게는 알 수 없는 것: | … 전체 성공률만 보고하여 다음을 판단하기 어려움. |
| 0을 걸치면 ‘구별 못 함’으로 판정한다(효과 없음이 아님). | 0을 포함하면 유의차 없음으로 판정함. |
| 각 단계가 벽 완성과 시방 합격에 주는 몫 | 단계별 벽 완성 · 시방 합격 기여도 |
| ‘손에 든 벽돌’을 아는 것이 먼저다. | 파지 벽돌 식별 우선: |
| 단계는 서로 기댄다. | 단계 간 상호 의존: |
| 시방 합격은 G3가 만든다. | G3와 시방 합격: |
| 현장 의미. | 현장 시사점: |
| 몫 있음 / 구별 못 함 (표) | 유의한 감소 / 유의차 없음 |
| 실패 분석에서 나온 질문 | 실패 분석에서 도출한 질문 |
| (그림 6 제목) G3(놓은 뒤 재배치)를 끄면 완성한 벽도 허용오차 6 mm를 넘는다 | G3(놓은 뒤 재배치) 제거 시 완성 벽도 허용오차 6 mm 초과 |
| (그림 4) 채움 판정은 시방보다 훨씬 느슨하다 | 채움 판정 기준은 시방 기준보다 훨씬 느슨함 |
| (그림 2) 가장 가까운 공급칸 = 어느 벽돌인가 | 최근접 공급칸 벽돌을 파지 벽돌로 판단 |

인계 문서의 뜻은 그대로 지킴: "검증" 결과 주장 없음, "개발 배치 100벽 · 최종 평가 전", "참값 (진단)", RQ2는 실패 분석에서 나온 질문으로 표시, 유의하지 않은 결과를 "효과 없음"으로 쓰지 않음("유의차 없음"). 1절 꼬리표 "검증 계획"은 사용자가 정한 1절 구성이라 그대로 둠. 감사의 글 · 참고문헌은 한 글자도 바꾸지 않음.

## 4. 글자 크기

| 항목 | pt |
|---|---|
| 국문 제목 · 영문 제목 | 48 · 40 |
| 저자 · 영문 이름 · 소속 | 32 · 32 · 24 |
| 절 제목 · 소제목 | 32 · 24 |
| 본문 | 16.5 (f판 17.5, 레퍼런스 20) |
| 표 · 그림/표 제목 · 1절 카드 | 14.5 · 13 · 15.5 |

그림 · 표 제목 9개가 들어가면서 본문이 17.5 → 16.5 pt로 줄었음. 17 pt는 왼쪽 단이 1.6 cm 넘침(배치 json의 시험 기록).

## 5. 점검

| 점검 | 결과 |
|---|---|
| 숫자 (pptx_text_check의 숫자 묶음, f판 대비) | 실험 숫자 같음. 차이는 그림 · 표 번호와 그 제목 안 숫자, 부제 "– 3단" → 제목 "3단", 지운 이메일 "01230"뿐 |
| PowerPoint 배치 | 두 단 끝 83.05 cm (쓸 수 있는 끝 83.05), 머리 영역 글 끝 12.82 cm (끝 14.14) |
| 그림 속 글 | 그림 1 · 2 · 4 · 5 · 6 다시 그림. 바꿀 글을 모두 찾았는지 스크립트가 확인. 그림 3은 이름표만 있어 그대로 |
| 화면 확인 | 머리 영역 로고와 겹침 없음, 그림 2 글이 상자 안에 들어감 |

## 6. 사용자 확인 필요

| 항목 | 내용 |
|---|---|
| 저자 · 소속 | 양식대로 이메일 · 회원 구분 · 교신저자 표시를 뺐음. 학회가 포스터에 교신저자 표시를 요구하면 되돌려야 함 |
| 본문 크기 16.5 pt | 레퍼런스 20 pt보다 작음. 키우려면 내용을 빼야 함 (f판 설명 3절의 후보) |
| 그림 5 · 6 | 그림 안 제목과 아래 "그림 n." 제목이 둘 다 있음. 그림 안 제목을 지우면 약 0.8 cm씩 확보 가능 |
| 참고문헌 [3] KCS 41 34 00 | 원문 번호 · 연도 미확인 (f판 설명과 같음) |
