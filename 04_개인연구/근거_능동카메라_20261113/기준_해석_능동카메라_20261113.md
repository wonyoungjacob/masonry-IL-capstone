# 기준의 실행 정의 (2차): 움직이는 깊이 카메라 (결과를 보기 전에 고정, 2026-11-13)

> 사용자 지시(11-13, 원문): "뎁스카메라를 쓰고 카메라 자체가 움직이는 상황 상정. 단 바퀴 달린 로봇을 얘기하는 것은 아님. 카메라 대수는 3대 이하로 제한. 카메라가 좌표상에서 움직이는 게 회전이 가능할 때 기준으로 수정하고 다시 고려해. 그리고 camera가 움직인다면 보통 real에선 어떤 식으로 구현하고 사람 눈이 원하는 semantic한 곳을 쫓아가는 것처럼 카메라도 물리적으로 쫓아가려면 어떻게 해야 하는지도 탑저널 컨퍼런스 문헌들을 통해 확인한 다음에 구축해."

## 3. 시선 규칙

| 항목 | 정의 | 근거 |
|---|---|---|
| 방식 | 로봇 좌표계의 3D 목표점 → 겨냥 역기구학(팬, 틸트) → 각속도 · 각가속도 한도 안에서 따라감. 제어 스텝(20 Hz)마다 갱신 | PR2 · Fetch point_head, iCub 시선 제어기, Spot, OK-Robot |
| 목표점 | 도면에서 온다. 집을 벽돌 = 공급 칸 k의 명목 위치의 벽돌 윗면 중심. 놓을 자리 = 설계 자리 k의 중심. 정답 좌표는 쓰지 않는다 | 벽돌 번호 k는 1차와 같이 과제가 준다(목표 정보) |
| 전환 신호 | 로봇 자기 상태만. 쥠 = 집게 관절 > 0.12 rad(열림 0, 벽돌을 쥐면 약 0.244). 놓음 = 쥔 뒤 다시 0.12 rad 아래. 대본의 단계 이름은 쓰지 않는다 | 대본 · 정책이 같은 규칙을 쓰게 하려고 |
| **선행** (lead) | 집을 벽돌 k → (쥠) → 놓을 자리 k → (놓음) → 다음에 집을 벽돌 k+1 | 사람: 쥘 곳을 손보다 먼저 보고, 운반이 시작되면 놓을 곳으로 옮기고, 접촉 뒤 곧 다음 대상으로 간다. 손은 보지 않는다(Johansson 2001, Land 1999, Lavoie 2018, Bowman 2009) |
| **공급 눈** (pick) | 집을 벽돌 k → (쥠) → 다음에 집을 벽돌 k+1 | 두 대가 일을 나눌 때 |
| **벽 눈** (slot) | 놓을 자리 k만 본다 | 두 대가 일을 나눌 때 |
| 손 추종 (hand) | 집게 끝(순기구학)을 따라간다. 비교용 | 로봇에서 흔한 '손 보기' |
| 고정 (fixed) | 두 영역 중심의 가운데 (0, 0.04, 0.235)를 계속 본다. 비교용 | 같은 자리에서 돌지 않을 때 |
| 시작 | 에피소드가 시작될 때 카메라는 첫 목표를 보고 멈춰 있다 | – |
| 측정할 때 | 카메라가 목표에 도착해 멈춘 뒤에 영상을 쓴다 | EyeRobot 2.0(1 s), ASC(2 s) |

## 4. 필수 조건 (1차 5개를 고친 것 + 1개 추가)

| 번호 | 1차 | 2차 (능동 카메라가 있는 세팅) |
|---|---|---|
| 1 | 정적 포함 100 %: 공급 16칸 · 놓을 자리 16곳이 고정 카메라 영상 가운데 90 % 안 + 50 % 이상 보임 | **시선 도달 100 %**: 공급 16칸 · 놓을 자리 16곳 각각을 그 세팅의 외부 카메라 중 적어도 한 대가 (가) 관절 범위 안에서 광축에 놓을 수 있고 (나) 그 거리가 0.3 ~ 3 m이며 (다) 그렇게 겨냥했을 때 보이는 비율이 50 % 이상(팔은 철수 자세, 놓을 자리 k는 앞선 벽돌을 설계 위치에 둔 장면). 공급 눈은 공급 16칸만, 벽 눈은 놓을 자리 16곳만 맡는다. 고정 카메라는 1차 정의 그대로 |
| 2 | 집기 접근: 집을 벽돌이 모든 영상에서 50 % 미만인 프레임 ≤ 5 % | 그대로. 능동 카메라는 시선 규칙대로 도는 동안의 실제 영상으로 센다(늦어서 대상이 영상 밖이면 안 보인 것) |
| 3 | 놓기 접근: 놓을 자리가 모든 영상에서 50 % 미만인 프레임 ≤ 5 % | 그대로 (위와 같음) |
| 4 | 공급대 벽돌 측정: 수평 95백분위 ≤ 2 mm, 못 잰 비율 ≤ 2 % | 기준값 그대로. **재는 카메라 = 손목 H0**, 집기 접근 자세(명목 칸 위 0.10 m)에서. 1차에서 R0에 쓴 절차와 같고 값은 이미 있다 |
| 5 | 놓인 벽돌 측정: 같은 기준 | 기준값 그대로. **재는 카메라 = 손목 H0**, 벽돌을 놓고 후퇴가 끝난 자세(놓은 자리 위 0.10 m, 집게 열림)에서 방금 놓은 벽돌을 잰다. 새로 잰다(6절) |
| 6 | 없음 | **추종**: 집기 접근 프레임 중 집을 벽돌(실제 위치)의 중심이, 놓기 접근 프레임 중 놓을 자리의 중심이 그 대상을 맡은 능동 카메라 영상의 가운데 50 %(가로 · 세로 각각 ± 25 %) 안에 있는 비율이 각각 ≥ 95 %. 맡은 카메라가 둘이면 둘 중 하나라도 |

- 4 · 5를 손목 카메라에 맡기는 이유 [판단]: 문헌에서 움직이는 D435로 1 m 밖에서 mm를 쟀다는 근거를 찾지 못했다(서보 분해능 0.088°가 1.1 m에서 1.7 mm). 정밀 측정은 끝단 가까이에서 한다(ETH In situ Fabricator, 1차 7.4절). 손목 카메라의 자세는 팔 순기구학에서 온다(1차의 H0 측정과 같은 가정).
- 외부 능동 카메라로 잰 오차는 **참고 값**으로 따로 잰다(6절). 필수 조건에는 쓰지 않는다.
- 고정 카메라만 쓰는 대조 세팅(5절)은 1 ~ 3을 1차 값 그대로 쓰고 4 · 5만 위 정의로 본다. 6은 해당 없음.
- 선정 규칙의 나머지(통과 세팅을 ACT 장당 성공률로 줄 세움, 동률 처리)는 1차 그대로다. '가장 가까운 세팅'의 정의도 그대로이고, 6번의 미달 정도는 (0.95 − 값) ÷ 0.95로 센다.

## 6. 측정 (선정 배치 820000 ~ 820099, 측정기는 커밋 `3341755` 그대로)

| 대상 | 카메라 | 절차 | 쓰임 |
|---|---|---|---|
| 공급대 벽돌 | 손목 H0 | 1차에서 잰 값(R0의 공급대 측정, 100장면 × 16)을 그대로 쓴다. 다시 재지 않는다 | 필수 조건 4 |
| 놓인 벽돌 | 손목 H0 | 대본으로 벽을 쌓으면서, 벽돌 k를 놓고 후퇴(retreat)가 끝난 때에 벽돌 k를 잰다. 사전 정보 = 설계 자리 (x, y, 방향), 윗면 높이 = 설계 높이 − 1차의 높이 보정값, 이웃 = 앞서 놓인 벽돌의 설계 자리. 100벽 × 16 | 필수 조건 5 |
| 공급대 벽돌 | 확정된 세팅의 외부 능동 카메라 | 팔은 철수 자세. 카메라가 벽돌마다 겨냥하고 멈춘 뒤 잰다 | 참고 |
| 놓인 벽돌 | 확정된 세팅의 외부 능동 카메라 | 팔이 철수 자세로 돌아온 때, 카메라가 자리 k를 겨냥하고 멈춘 뒤 잰다 | 참고 |

|---|---|---|
| 오차 없음 | 실제 각 | 1차의 고정 카메라와 같은 가정 |
| 정밀급 | 분해능 0.013°로 반올림한 각 | FLIR PTU-E46-17. 백래시 · 반복정밀도는 문서에서 확인하지 못해 넣지 않았다(낙관적) |
