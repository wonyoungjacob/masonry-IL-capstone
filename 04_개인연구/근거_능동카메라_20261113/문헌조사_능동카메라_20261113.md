# 문헌 조사: 움직이는 카메라의 실제 구현과 시선 제어 (2026-11-13)

> 사용자 지시(11-13): "camera가 움직인다면 보통 real에선 어떤 식으로 구현하고 사람 눈이 원하는 semantic한 곳을 쫓아가는 것처럼 카메라도 물리적으로 쫓아가려면 어떻게 해야 하는지 탑저널 · 컨퍼런스 문헌으로 확인한 다음에 구축".
> 방법: 웹 조사 2건(하위 조사 작업)을 돌리고, 핵심 4건은 내가 원문을 다시 열어 확인했다. 수치는 출처의 진술이다. 논문에 인용하기 전에 원문을 다시 확인한다.
> 표기: **확인** = 논문 본문 · 프로젝트 페이지 · 제조사 문서에서 읽음, **초록** = 초록 · 서지 페이지만 읽음, **미확인** = 검색 요약뿐. ★ = 내가 다시 열어 확인함.

## 1. 실제 로봇에서 카메라를 움직이는 방식

| 방식 | 사례 (학회 · 연도) | 장치 | 표기 |
|---|---|---|---|
| 2축 목 (좌우 + 상하) | Stretch (ICRA 2022, arXiv 2109.10892) | **D435i 깊이 카메라를 팬 · 틸트 머리에 장착**, 팬 346° · 틸트 115°. 구동은 Dynamixel 서보 2개(제조사 안내) | 확인 ★ |
| 2축 목 | Open-TeleVision (CoRL 2024, 2407.01512) | 3D 프린트 짐벌(yaw, pitch), Dynamixel XL330, ZED Mini 스테레오, 60 Hz | 확인 |
| 2축 목 | TWIST2 (arXiv 2511.02832, 예비 논문) | Dynamixel XC330 2개, 약 250달러, ZED Mini | 확인 |
| 2축 목 | PR2, Fetch, TIAGo | 머리 팬 · 틸트 + RGB-D (Fetch: Primesense, TIAGo: Orbbec Astra) | 확인 (제조사 · 인용 논문) |
| 2축 짐벌 (빠른 것) | Eye, Robot (CoRL 2025, 2506.10968) | 직결 BLDC 모터 2개, 60°를 20 ms에. 로봇 받침에 고정. 어안 RGB | 확인 |
| 카메라 전용 팔 (5 ~ 7축) | AV-ALOHA (ICRA 2025, 2409.17435) | ViperX-300을 7축으로 고쳐 ZED mini를 듦 | 확인 ★ |
| 카메라 전용 팔 | Vision in Action (CoRL 2025, 2506.15666) | 6축 ARX5 팔을 목으로, 끝에 iPhone(RGB + 깊이) | 확인 |
| 카메라 전용 팔 | ActiveUMI (arXiv 2510.01607, 예비 논문) | 6축 팔 3대 중 1대가 머리 카메라 | 확인 |
| 줌 짐벌 | AVR (arXiv 2503.01439, 예비 논문) | 전동 줌 산업용 카메라 + 2축 짐벌 | 확인 |
| 건설: 외부 추적 계측기 | Fastbrick 특허 US11441899B2, Hilti JaiBot (RA-L 2025, 2501.14280) | 레이저 트래커 · 토털 스테이션이 끝단의 표적을 따라 돎. mm 수준. 시선이 끊기면 못 씀 | 확인 (특허 · 논문) |
| 건설: 끝단 센서 | ETH In situ Fabricator (Construction Robotics 2017, 1701.03573) | 끝단의 레이저 거리계로 주변을 훑어 기준에 맞춤. 벽돌 벽 최대 조립 오차 7 mm | 확인 |

- [사실] 조사한 범위에서 조작 정책에 상용 PTZ 장치나 직선 레일 위 카메라를 쓴 논문은 찾지 못했다. 벽돌을 따라가는 팬 · 틸트 RGB-D 카메라도 찾지 못했다.
- [사실] 움직이는 카메라는 거의 RGB다(ZED mini, 어안, iPhone). 움직이는 RealSense 깊이 카메라의 하드웨어 선례는 Stretch다.

## 2. 능동 카메라가 있을 때와 없을 때 (보고된 성공률)

| 연구 | 결과 | 표기 |
|---|---|---|
| AV-ALOHA (ACT) | 바늘 꿰기: 능동 52 %, 능동 + 손목 52 %, 고정 30 %, 고정 + 손목 22 %. 보이는 과제는 반대: 슬롯 끼우기 고정 + 손목 78 %, 능동 50 %. "the added complexity from variation in viewpoint can negatively impact performance" | 확인 ★ |
| Vision in Action | 능동 머리만 / 능동 + 손목 / 가슴 고정 + 손목: 90 / 80 / 70 %, 80 / 65 / 20 %, 55 / 25 / 0 %. 손목 카메라를 더하면 평균 18 %p 하락 | 확인 (그림에서 읽음) |
| Eye, Robot | 지우개 옮기기: 눈 / 외부 / 손목 / 손목 + 외부 = 60 / 0 / 100 / 60 %. 놓을 곳을 흔들면 100 / – / 10 / 40 % | 확인 |
| ActiveUMI | 능동 / 고정 머리 / 손목만: 70 / 42 / 26 % (새 환경 56 / 16 / 6 %) | 확인 |
| MIT 목 (arXiv 2411.00704) | 아래 선반의 컵: 움직이는 목 95 %, 고정 광각 0 % | 확인 |
| ActiveAlign (arXiv 2610.23378) | 주의: π0.5 앞에 카메라 재배치를 그냥 붙이면 LIBERO 46.3 → 11.5 % | 초록 |

- [판단] 이득은 가림 · 탐색 · 넓은 작업 영역에서 나온다. 잘 보이는 정밀 과제에서는 이득이 없거나 손해다. 보고된 끝 오차는 cm 단위이고, 능동 카메라 덕에 6 mm급 배치를 했다는 논문은 찾지 못했다.

## 3. 움직이는 깊이 카메라로 mm를 잴 수 있는가

| 출처 | 내용 | 표기 |
|---|---|---|
| Robotis XM430-W350 안내서 | 분해능 4096 펄스/회전 (0.088°), 백래시 15분 (0.25°) | 확인 ★ |
| FLIR PTU-E46 설정 안내 | E46-17: 분해능 0.013°, 300°/s. E46-70: 0.003°, 60°/s. 반복정밀도 · 백래시는 문서에 없음 | 확인 |
| Birbach (ICRA 2012, DLR Justin) | 팬 · 틸트 머리 스테레오를 자가 보정: 잔차가 1 m에서 약 0.7 mm. 흔들림과 번짐을 줄이려 머리 속도를 24°/s로 제한 | 확인 |
| Stretch 보정 안내 | ArUco로 머리 카메라를 보정. 머리를 위로 들면 틸트 백래시 때문에 오차가 커짐 | 확인 |
| RealSense D400 자료 (2026-03) | D43x: 2 m까지 깊이 정확도 ±2 %. D405: 0.5 m까지 ±2 %, 범위 7 cm ~ 1 m | 확인 |
| Ahn (UR 2019) | D435: 1 m까지 오차 5 mm 안, 그 뒤 제곱으로 증가 | 확인 |

- [사실] 계산(내 산수): 1.1 m 거리에서 0.088°는 1.7 mm, 0.25°는 4.8 mm, 0.013°는 0.25 mm다.
- [사실] 팬 · 틸트나 목에 단 깊이 카메라로 물체 자세를 mm 수준으로 쟀다는 논문은 찾지 못했다.
- [판단] 서보로 도는 D435로 1 m 넘는 거리에서 2 mm를 재는 것은 문헌이 뒷받침하지 않는다. mm는 가까이(끝단 센서)에서 재거나 외부 추적 계측기로 잰다.

## 4. 카메라 상태가 정책에 들어가는 방식

| 연구 | 관측 | 행동 | 표기 |
|---|---|---|---|
| AV-ALOHA | 카메라 팔 관절 포함 | 한 정책이 21개 관절(팔 + 카메라 팔) | 확인 |
| Open-TeleVision | 관절값 | 28차원 중 목 2 | 확인 |
| Vision in Action | 목 · 양팔 끝단 자세 | 한 정책이 목 + 팔 | 확인 |
| Eye, Robot | 시선 방향 3D 벡터 + 관절 | 눈은 따로 학습한 정책, 팔 정책은 팔만 | 확인 |
| 도쿄대 목 (arXiv 2506.17624) | 팔 정책 입력에 목 각도 | 목은 별도 모형 | 확인 |

- [판단] 표준은 카메라 관절을 관측과 행동에 모두 넣는 한 정책이다. 시선을 따로 정하는 경우에도 시선 방향은 팔 정책의 입력으로 준다.

## 5. 사람의 눈과 손 (시선이 가는 곳)

| 연구 | 내용 | 표기 |
|---|---|---|
| Johansson 외 (J. Neurosci. 2001) | 접촉 사건이 일어나는 곳(쥘 곳, 목표, 받침면)이 반드시 보는 곳이다. "Subjects never fixated the hand or the moving bar." 시선이 손을 이끈다 | 초록 (앞선 시간 ms는 미확인) |
| Land 외 (Perception 1999) | 첫 주시가 조작보다 0.56 s 앞선다. 앞 물체의 조작이 끝나기 약 0.61 s 전에 다음 물체로 간다 | 초록 |
| Hayhoe · Ballard (TiCS 2005) | 눈은 가장 눈에 띄는 곳이 아니라 그 일에 가장 필요한 곳으로 간다. 필요할 때 바로 보는 방식 | 확인 |
| Lavoie 외 (J. Vision 2018) | 집을 물체를 손이 닿기 0.5 s 이상 전부터 보고, 운반이 시작되면 놓을 곳으로 바로 옮겨 놓을 때까지 본다. 손이나 든 물체는 거의 보지 않는다 | 초록 (내 재확인은 접속 거부로 실패) |
| Bowman 외 (Exp. Brain Res. 2009) | 접촉 약 100 ms 뒤에 다음 대상으로 옮긴다 | 초록 |

## 6. 로봇이 카메라를 의미 있는 곳으로 돌리는 방법

많이 쓰는 순서(조사 작업의 판단).

| 방법 | 사례 | 필요한 것 | 표기 |
|---|---|---|---|
| 기하 겨냥 (look-at): 로봇 좌표계의 3D 점 → 겨냥 역기구학 → 속도 제한 | PR2 · Fetch의 point_head, iCub 시선 제어기(RSS 2016: 3D 주시점, 도약 + 추종), Spot 팔 시선, OK-Robot(RSS 2024: 기억한 물체 위치로 머리 카메라를 돌림) | 대상의 3D 위치, 보정된 머리 기구학 | 확인 (코드 · 논문) |
| 조작자의 머리 자세를 모방 | Open-TeleVision, AV-ALOHA, Vision in Action, ActiveUMI | VR 원격조작과 카메라 동작이 든 시연 | 확인 |
| 검출기로 물체를 영상 가운데에 맞춤 | ASC(RA-L), HomeRobot(CoRL 2023), EyeRobot 2.0(arXiv 2610.03710: 언어 → SAM3 → 3D 중심, 30 Hz) | 프레임마다 믿을 만한 검출, 깊이 | 확인 |
| 과제 보상 강화학습 | Eye, Robot, DISaM(CoRL 2024), Observe Then Act | 다른 시점을 그릴 방법, 보상을 줄 조작 정책 | 확인 |
| 정보 이득 (다음 시점) | Morrison(ICRA 2019), Breyer(IROS 2022), SAM-RL(RSS 2023) | 부피 지도 · 불확실도, 보통 팔 위 카메라 | 확인 |
| 사람 시선 예측 + 가운데 잘라 보기 (카메라는 안 움직임) | Kim 외(RA-L 2020, 2021: 바늘 꿰기 81 %, 잘라 본 영상 없이는 12.5 %), Look, Focus, Act(ICRA 2026) | 시선 추적 자료, 넓고 해상도 높은 영상 | 확인 (2021), 초록 (2020) |
| 언어로 카메라 동작 | SaPaVe(CVPR 2026), ActiveVLA | 큰 자료. 가장 새롭고 덜 성숙 | 확인 · 초록 |

- [사실] 멈춘 뒤 본다: EyeRobot 2.0은 행동 전 1 s, ASC는 2 s 동안 대상이 가운데 있어야 한다. 번짐을 줄이려 회전 속도를 제한한다(Eye, Robot, Birbach).
- [사실] 고전 근거: 시각 서보(Chaumette · Hutchinson, IEEE RAM 2006: 오차 e = s − s*를 줄이는 속도 제어), 능동 지각(Bajcsy 1988, 2018).

## 7. 확인하지 못한 것

- Johansson 2001의 앞선 시간(ms). 본문에 접속하지 못했다.
- Ballard 1991, Bajcsy 1988의 원문(초록 · 재인용만).
- Hadrian X, SAM100의 정확도를 다룬 심사 논문(제조사 · 특허 · 업계 기사만 있음). Automation in Construction 본문은 접속 거부.
- 검출기(SAM 2) → 3D 점 → 겨냥 → 속도 제한 팬 · 틸트로 이어지는 한 편의 논문.
- Science Robotics · IJRR · T-RO에서 이 질문을 직접 다룬 논문.

## 8. 우리 설계에 주는 뜻 [판단]

| 결정 | 근거 |
|---|---|
| 장치: 고정 받침 위 2축 팬 · 틸트 + D435급 깊이 카메라 | 가장 흔한 실제 구현(2축 목). 깊이 카메라 선례는 Stretch. 카메라 전용 팔은 값이 비싸고 사용자 지시가 '회전'이다 |
| 시선: 기하 겨냥. 목표점은 도면에서, 전환은 로봇 자기 상태에서 | 실제 로봇에서 가장 흔한 방식. 벽돌 위치와 놓을 자리를 도면으로 알고 있어 검출기가 필요 없다 |
| 보는 곳: 집을 벽돌 → (쥠) → 놓을 자리 → (놓음) → 다음 벽돌. 손은 따라가지 않는다 | Johansson, Land, Lavoie의 사람 시선 순서 |
| 멈춘 뒤 측정, 각속도 제한 | 4 · 6절 |
| mm 측정은 손목 카메라가 가까이서 맡는다 | 3절. 외부 능동 카메라의 측정값은 참고로 따로 잰다 |
| 정책에는 팬 · 틸트 각을 관측으로 준다 | 4절 |
| 고정 카메라 세팅을 대조로 남긴다 | 2절: 움직이는 시점이 손해인 경우가 보고됨 |
| 회전만으로는 가림이 줄지 않는다 | 같은 자리에서 본 시선은 그대로다. 회전의 이득은 한 대가 넓은 영역을 맡는 것과 더 가까이 다는 것이다 |
