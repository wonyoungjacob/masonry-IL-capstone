### 실제로 쓸 한도 (지시 문서 4.2)

| 항목 | 값 |
|---|---|
| 학습 RAM | `MemoryMax=36G` (= min(60.4 × 0.6, 60.4 − 12)), `MemorySwapMax=2G`, `nice 10`, 학습마다 별도 scope |
| 평가 RAM | `MemoryMax=30G` (= 60.4 × 0.5) |
| GPU | 한 번에 하나. 학습 · 평가 · 수집(영상 그리기)을 겹치지 않음 |
| 데이터 로딩 | 작업자 4개 (6개를 넘기지 않음) |
| 학습 나눠 돌리기 | 2만 스텝마다 저장하고 프로세스를 끝낸 뒤 이어 함 |
| VRAM | 200스텝 시험으로 최고값 기록. 26 GB를 넘으면 배치 반으로 |
| 평가 병렬 수 | P = min(8, (사용 가능 RAM − 12) ÷ 프로세스당 RAM, (남은 VRAM − 4) ÷ 프로세스당 VRAM). 4단계에서 재서 기록 |
| 디스크 | 수집 전 2벽으로 용량 추정. 남은 용량의 50 %(지금 399 G)를 넘으면 벽 수를 줄임. 남은 용량 50 G 아래면 멈춤 |
| 캐시 예열 | 데이터셋이 24 G(RAM의 40 %) 이하일 때만 |
| 메모리 감시 | 5분마다 사용 가능 RAM 기록. 6 G 아래로 10분 넘으면 그 작업을 다시 시작 |
