## 2. 카메라

| 항목 | 정의 |
|---|---|
| 화각 | 가로 87° → 4 : 3 영상의 세로 화각 70.9°. WA1 45°, WB1 50°, H0 80°는 지금 값 그대로(세로 화각) |
| 수직 카메라의 방향 | 영상 위쪽 = 세계 +y (지금의 top과 같음) |
| 공급 영역 중심 | (0, −0.52, 0.38). SC1 · SD1의 보는 점 |
| H1 | 집게 부착 좌표(z = 손끝 방향, y = 닫힘축, x = 든 벽돌의 길이 방향)로 (0.100, 0, 0.000) m, 손끝(패드 중심)을 봄 |
| H2 | (0.060, −0.110, 0.050) m, 손끝에서 접근축으로 0.12 m 더 간 곳의 닫힘축 쪽 0.03 m 옆을 봄 |
| 몸체 | 카메라 몸체 = 반지름 0.05 m 구. 팔 · 집게 · 든 벽돌이 대본 궤적 20벽에서 이 구에 0.05 m 안으로 들어오면 겹침으로 본다 |
| 겹치면 | 고정 카메라: 로봇 받침대 축에서 멀어지는 수평 방향으로 0.05 m씩 옮겨 처음 겹치지 않는 곳. 보는 점은 그대로. 손목: 집게 · 든 벽돌과 0.03 m 안이면 닫힘축 / 길이 방향 바깥으로 0.01 m씩 |
| 깊이 잡음 | 고정 = D435급(기선 50 mm, 0.3 ~ 3 m), 손목 = D405급(기선 18 mm, 0.07 ~ 0.5 m). 시차 잡음 0.08 화소. 이웃 화소끼리 7화소 상자 평균으로 상관. 범위 밖은 무효 |

## 3. 기하 지표 (2단계)

대본 궤적 20벽(800000 ~ 800019)을 5스텝마다 재생. 분할 · 깊이 영상은 640 × 480으로 그린다(비율 계산용, 원본과 화각 같음).

| 항목 | 정의 |
|---|---|
| 구간 | 집기 접근 = to_supply + grasp_descend / 집기 = grasp_close + grasp_lift / 운반 = to_wall / 놓기 접근 = place_align + place_descend + place_servo + place_lower / 놓기 = place_unload + place_open + retreat |
| 가리지 않았을 때의 화소 | 대상 상자의 모서리 8개를 영상에 투영한 볼록 다각형의 넓이(영상 밖 부분 포함). 영상 밖에 있으면 보이는 비율 0 |
| 집을 벽돌 · 든 벽돌 | 보이는 화소 = 분할 영상에서 그 벽돌인 화소 수. 집을 벽돌은 쥐기 전(집기 접근), 든 벽돌은 쥔 뒤(집기의 grasp_lift, 운반, 놓기 접근) |
| 놓을 자리 | 설계 자리 상자(L × W × H). 보이는 화소 = 다각형 안에서, 그려진 깊이가 상자 앞면보다 가깝지 않은(앞에 가리는 것이 없는) 화소 수. 벽돌이 자리에 들어가 있으면 보이는 것으로 센다 |
| 손끝 | 양쪽 손끝 판(fingertip) 두 장. 보이는 화소 = 분할 영상에서 손끝 · 패드 형상인 화소 수, 분모 = 두 판의 투영 다각형 넓이의 합 |
| 가림 지표 | 구간 × 대상마다 보이는 비율의 중앙값과, 50 % 미만인 프레임 비율 |
| 화소 크기 | 대상 윗면 중심까지의 광축 거리 z로 계산. 원본 mm/화소 = z ÷ 초점거리(원본 화소). 224 영상의 90 mm = 90 mm ÷ (원본 mm/화소 × 1280/224). 고정 카메라는 그 영역(공급 16칸 또는 놓을 자리 16곳, G1은 둘 다) 중 가장 먼 것. 손목은 접근 높이(잡는 높이 + 0.10 m)에서 |
| 입사각 | 대상 윗면 중심으로 가는 시선과 연직선 사이 각의 최대값(0° = 수직으로 내려다봄) |
| 깊이 잡음 예측 | 가장 먼 대상 거리에서의 σ |
| 정적 포함 | 팔이 철수 자세일 때, 영역의 윗면 사각형(공급 칸 = 명목 자리의 벽돌 윗면, 놓을 자리 = 그 자리의 받침면)의 네 모서리가 모두 영상 가운데 90 % 안에 있고, 그 사각형의 보이는 비율이 50 % 이상. 놓을 자리 k는 앞선 벽돌 0 ~ k−1을 설계 위치에 놓은 장면에서 본다. 포함만 본 값(가림 무시)도 함께 적는다 |

## 4. 세팅 구성 (6.4의 '최선')

| 항목 | 정의 |
|---|---|
| SA · SB 중 최선 | 집기 접근 구간에서 집을 벽돌이 50 % 미만으로 보이는 프레임 비율이 가장 낮은 것 |
| WA · WC · (WD1, WE1) 중 최선 | 놓기 접근 구간에서 놓을 자리가 50 % 미만으로 보이는 프레임 비율이 가장 낮은 것 |
| 같으면 | 차이가 0.5 %p 이내면 같은 것으로 보고, 원본 mm/화소가 작은 것 |
| 손목 최선 | (집기 접근의 집을 벽돌 보이는 비율 중앙값) + (놓기 접근의 놓을 자리 보이는 비율 중앙값)이 가장 큰 것 |
| G1 | 격자 x ∈ {1.4, 1.8, 2.2} × y ∈ {−0.5, 0, 0.5} × z ∈ {1.2, 1.7, 2.2} (27곳), 보는 점 = 두 영역 중심의 가운데 (0, 0.04, 0.235), 가로 87°. 정적 포함(포함만)이 100 %인 곳 중 [집기 접근의 집을 벽돌 50 % 미만 프레임 비율 + 놓기 접근의 놓을 자리 50 % 미만 프레임 비율]이 가장 작은 곳. 격자 탐색은 궤적 5벽(800000 ~ 800004)으로 한다. 100 %인 곳이 없으면 포함 비율이 가장 큰 곳 중에서 고르고, RE는 정적 포함 미달로 표시 |
| 겹침으로 옮긴 카메라 | 옮긴 위치로 지표를 다시 계산해 그 값으로 고른다 |

## 5. 선정 규칙 (6.7)의 계산

| 항목 | 정의 |
|---|---|
| 정적 포함 100 % | 공급 16칸과 놓을 자리 16곳이 각각 그 세팅의 고정 카메라 중 적어도 한 대에 3절의 뜻으로 포함 |
| 가림 조건 | 집기 접근 프레임 중 집을 벽돌이 그 세팅의 **모든** 영상에서 50 % 미만인 비율 ≤ 5 %, **그리고** 놓기 접근 프레임 중 놓을 자리가 모든 영상에서 50 % 미만인 비율 ≤ 5 %. 두 구간을 따로 본다(더 엄격한 쪽) |
| 세팅의 가림 지표 (동률 판정용) | 위 두 비율의 합 |
| 측정 오차 | 6절 |
| 순위 | ACT seed 1000의 장당 성공률. 구간 = 장면 50개 단위 부트스트랩(10,000번, 백분위 2.5 ~ 97.5) |
| 1 · 2위 추가 학습 | 필수 조건을 통과한 세팅 중 1 · 2위에 seed 2000 · 3000을 더 학습. 최종 비교 = seed 3개의 시행을 모은 장당 성공률, 장면 단위 부트스트랩(같은 장면의 seed 3개를 함께 뽑음) |
| 동률 | 1위의 구간과 겹치는 세팅끼리는 세팅의 가림 지표가 낮은 쪽, 차이가 0.5 %p 이내면 영상 수가 적은 쪽 |
| 탈락한 세팅 | 표시만 하고 ACT 학습 · 시험은 6개 모두 한다(R0 대조 포함). 순위에는 넣지 않는다 |

## 6. 측정 오차 (3단계)

| 항목 | 정의 |
|---|---|
| 측정기 | `sim/prl/perception.py` 하나를 모든 세팅에 똑같이 쓴다. 입력 = 그 카메라의 원본 색 + 잡음 넣은 깊이 + 카메라 보정값 + 도면(벽돌 치수, 설계 위치, 공급대 칸 배치 · 높이). 시뮬레이터 참값은 오차 계산에만 쓴다 |
| 개발 | 측정기는 개발용 시작값 800200 ~ 800299에서만 만들고 고친다. 커밋으로 고정한 뒤에 820000 ~ 820099를 잰다. 잰 뒤에는 고치지 않는다 |
| 공급대의 벽돌 | 장면을 초기화하고 팔이 철수 자세일 때 16장을 각각 잰다(100장면 × 16). 카메라 = 그 세팅의 공급 쪽 고정 카메라(RE는 G1). 없으면(R0) 손목 카메라로, 팔을 그 칸의 명목 위치 위 접근 자세(잡는 높이 + 0.10 m, 회전 0)에 두고 잰다 |
| 놓인 벽돌 | 대본으로 벽을 쌓으면서, 벽돌 k를 놓고 팔이 철수 자세로 돌아온 때에 방금 놓은 벽돌 k를 잰다(100벽 × 16). 카메라 = 그 세팅의 벽 쪽 고정 카메라(R0는 WA1, RE는 G1) |
| 손에 든 벽돌 | 같은 벽에서 운반(to_wall)이 끝난 때(자리 위 0.10 m). 벽 쪽 고정 카메라와 손목 카메라로 각각 재어 둘 다 적는다. 필수 조건에는 넣지 않는다(지시 문서 6.7) |
| 못 잰 것 | 측정기가 값을 내지 못한 경우. 값을 냈으면 아무리 틀려도 오차 분포에 넣는다 |
| 오차 | 수평(mm), 회전(°, 180° 대칭으로 접음. 반장은 90° 대칭), 높이(mm). 중앙값과 95백분위 |
| 필수 조건 | 공급대 벽돌과 놓인 벽돌 각각 수평 오차 95백분위 ≤ 2 mm, 못 잰 비율 ≤ 2 % |

## 7. 학습과 시험 (4단계)

| 항목 | 정의 |
|---|---|
| 시연 | 대본으로 300벽을 목표(810000부터 차례로). 시방 합격 · 완주 · 과부하 해제 0번인 벽만 쓴다(기존과 같은 '깨끗한 합격'). 벽돌 한 장 = 에피소드 1개 |
| 기록하는 카메라 | 세팅 6개에 들어가는 카메라만(2단계가 끝나면 정해짐). 224 × 224 정책 입력 영상으로 저장 |
| 학습 | `lerobot-train --policy.type=act`, 배치 32, 3만 스텝, seed 1000, 그 밖은 본 학습과 같은 기본 정책 설정. 입력 = 그 세팅의 영상 + 관절 6 + 집게 + 목표 정보 5 |
| 시험 | 장 단위 16자리 × 50장면(820000 ~ 820049), 정책 단독, 행동 묶음 설정은 정책 기본값 |
