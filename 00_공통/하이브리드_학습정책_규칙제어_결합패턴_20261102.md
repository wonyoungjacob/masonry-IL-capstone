# 학습 정책과 규칙 기반 제어의 하이브리드 결합 패턴

2026-11-02. 범위는 건설에 한정하지 않은 로봇 일반(매니퓰레이션, 보행, 드론, 자율주행)이다. ICRA·IROS·RSS·CoRL·T-RO·IJRR·Science Robotics 등에 실린 연구를 위주로 정리했다.

## 1. 패턴별 정리

### P1. 계층(직렬) 구조: 학습 상위 정책 → 고전 하위 제어기

**작동 원리.** 정책은 느린 주기 $f_\pi$로 "무엇을 할지"를 목표값으로 내고, 하위 제어기(low-level controller)는 빠른 주기 $f_c \gg f_\pi$로 그 목표를 추종한다.

$$a_k = \pi_\theta(o_k)\quad (f_\pi),\qquad u(t) = C\big(a_k,\ x(t)\big)\quad (f_c)$$

행동 공간(action space)을 고르는 것이 곧 학습과 제어의 분담을 고르는 것이다.

| 행동 $a$ | 하위 제어기 $C$ | 쓰이는 곳 |
|---|---|---|
| 관절 목표 위치 $q^*$ | 관절 PD: $\tau = K_p(q^*-q) - K_d\dot q$ | 보행 RL, ACT·Diffusion Policy 대부분 |
| 말단 변위 $\Delta x$ (+ 임피던스 이득 $K$) | OSC/임피던스: $\tau = J^\top \Lambda\,(K e - D\dot x) + h(q,\dot q)$ | 접촉 작업. 이득까지 내면 가변 임피던스 |
| 총추력·몸체 각속도 $(c,\ \omega^*)$ | 비행 제어기의 각속도 제어 | 드론 |
| 궤적·경유점·발 디딤 위치 | MPC, 궤적 추종, 전신 제어 | 드론, 보행 |
| 관절 토크 $\tau$ | 없음(포화만) | 순수 학습. 실기에서는 드묾 |

```
 관측 o_k ──► [ 학습 정책 π_θ ] ──a_k (목표값, 10~50 Hz)──► [ 보간·한계 ] ──► [ 하위 제어기 C ] ──u (0.5~1 kHz)──► 로봇
                                                                                   ▲
                                                                    상태 x(t) ─────┘  (빠른 되먹임)
```

**장점.** 안정화와 접촉 순응을 검증된 제어기가 맡으므로 정책 주기가 느려도 된다. 시뮬레이션–실기 차이 일부를 하위 제어기가 흡수한다. 행동이 물리적으로 의미 있어 학습이 쉽다.
**단점.** 하위 제어기의 이득·대역폭이 정책 성능의 상한이 된다. 시뮬레이션과 실기의 하위 제어기(이득, 지연, 보간)가 다르면 정책이 그대로 옮겨지지 않는다.

| 연구 | 학습 정책 (입력 → 출력) | 고전 제어 (입력 → 출력) | 결합 동기 |
|---|---|---|---|
| Hwangbo et al. 2019, *Science Robotics* (ANYmal) | 몸체·관절 상태, 명령 → 관절 목표 위치 (보행 200 Hz) | 실기: 구동기 모듈 안의 관절 PD → 토크. 시뮬레이션: 학습한 actuator network가 "목표 위치 → 토크" 사슬(PD, 전류 루프, SEA) 전체를 대신함 | 토크를 직접 내면 실기 이전이 어려움. 구동기 동역학을 모델로 흡수 |
| Martín-Martín et al. 2019, IROS (VICES) | 상태 → 말단 위치·자세 변위 + 강성 $k_p$·감쇠 $k_v$ (20 Hz) | 동역학 일관 OSC, $u = J^\top f$ → 관절 토크 (500 Hz) | 접촉 작업은 말단 가변 임피던스 행동 공간이 관절 공간보다 학습·전이가 잘 됨 |
| Kaufmann et al. 2023, *Nature* (Swift) | 상태 추정치 → 질량 정규화 총추력 + 몸체 각속도 | 기체 탑재 저수준 제어기(Betaflight) → 모터 | 고속 비행의 안정화는 기존 제어기, 정책은 경주 전략만 |
| Gangapurwala et al. 2022, T-RO (RLOC) | ① 지형·상태 → 발 디딤 계획 ② 보조 RL: 전신 추종 보정 토크(잔차, ±40 N·m로 자름) ③ 보조 RL: 넘어짐 회복 | 무게중심·발 궤적 계획 + 계층 QP 전신 제어기 → 관절 토크 | 발 디딤 계획은 학습이, 몸체 동역학 추종은 모델 기반이 강함. P1에 P2(잔차)와 P4(회복 전환)를 겹친 사례 |

### P2. 잔차(병렬) 구조: Residual Policy

$$a = a_{\text{base}}(s) + \alpha\,\pi_\theta(s),\qquad \|\pi_\theta(s)\|_\infty \le \delta$$

기준 제어기 $a_{\text{base}}$(손으로 설계한 제어기, 물리식, 궤적 생성기)가 대부분을 하고, 학습은 마찰·접촉·모델 오차처럼 모델링하기 어려운 부분만 보정한다. $\alpha$와 $\delta$로 보정 폭을 묶는다.

```
             ┌─► [ 기준 제어기 a_base(s) ] ───────┐
 상태 s ─────┤                                    (+)──► a ──► [ 하위 제어기 ] ──► 로봇
             └─► [ 잔차 정책 π_θ(s) ] ──×α, |·|≤δ ┘
```

변형은 네 가지다. (a) 손으로 설계한 제어기 + 잔차 RL. (b) 물리식 + 잔차 회귀(residual physics). (c) 주기 궤적 생성기의 매개변수 변조 + 잔차(PMTG). (d) 학습한 BC 정책 + 잔차 RL(기준도 학습).

**장점.** 처음부터 쓸 만한 동작에서 출발하므로 탐색이 안전하고 표본 효율이 높다. 잔차 폭을 묶으면 최악의 경우에도 기준 제어기 근처에 머문다.
**단점.** 기준 제어기의 전략 자체가 틀린 곳은 고칠 수 없다. 잔차가 커지면 기준 제어기의 안정성 보장이 사라진다.
**도메인.** 접촉이 많은 조립·삽입, 투척, 보행.

| 연구 | 학습 정책 | 고전 제어 | 결합 동기 |
|---|---|---|---|
| Johannink et al. 2019, ICRA (Residual RL) | 상태 → 잔차 행동 | 손으로 설계한 제어기 → 기본 행동 | 마찰·접촉은 모델링이 어렵고 순수 RL은 표본이 많이 듦. 실기 블록 사이 끼우기에서 서 있는 블록의 방향을 흩은 조건은 손 설계 제어기 2/20, 잔차 RL 15/20. 정렬된 조건은 둘 다 20/20 |
| Zeng et al. 2020, T-RO (TossingBot) | 영상 → 집기 + 놓는 속도의 잔차 $\delta$ | 이상 탄도 물리식 → 놓는 속도 $\hat v$. 실행값 $v = \hat v + \delta$ | 물리식이 일반화를 주고, 잔차가 물체별 공력·집는 위치 차이를 보정. 집기와 던지기를 함께 학습 |
| Iscen et al. 2018, CoRL (PMTG); Lee et al. 2020, *Science Robotics* | 상태 → 궤적 생성기 매개변수(다리별 주파수) + 발 목표 위치 잔차 | 주기 발 궤적 생성기 + 해석적 IK + 관절 PD | 보행 주기 구조를 사전 지식으로 넣어 학습을 안정화 |
| Ankile et al. 2025, ICRA (ResiP) | 잔차 RL | 동결한 청크 BC 정책(학습된 기준) | 정밀 조립의 마지막 mm 보정. 기준이 학습이므로 엄밀히는 "학습 + 학습" |

### P3. 가드레일/안전 필터 구조: Safety Filter

$$a_{\text{safe}} = \Pi_{\mathcal S}(a_\theta) = \arg\min_{a\,\in\,\mathcal A_{\text{safe}}(x)} \|a - a_\theta\|^2$$

정책은 성능만 보고 행동을 제안하고, 필터는 안전 집합 $\mathcal S$를 지키는 범위에서 그 행동을 가장 적게 바꿔 통과시킨다(minimally invasive). 필터 제약이 비활성이면 시스템은 학습 정책 그대로다.

```
 o ──► [ 학습 정책 π_θ ] ──a_θ──► [ 안전 필터 Π_S ] ──a_safe──► [ 하위 제어기 ] ──► 로봇
                                    ▲  제약: 한계값 / CBF / MPC / HJ      │
                                    └──────────── 상태 x ◄────────────────┘
```

필터의 종류는 한계값 자르기(clipping) → 규칙 필터 → 안전층(제약의 선형 근사) → CBF-QP → 예측 안전 필터(MPC) → HJ 도달 가능성 순으로, 뒤로 갈수록 보장이 강하지만 모델 의존과 계산량이 크다. 수식은 2장에 있다.

**장점.** 학습 정책을 바꾸지 않고 붙일 수 있다. 정책이 무엇이든 제약 만족을 보장할 수 있다(모델이 맞다는 전제에서).
**단점.** 보장은 모델 정확도에 달려 있다. 필터가 자주 개입하면 정책이 학습한 분포에서 벗어나 성능이 떨어진다. 안전 집합을 정의하기 어려운 작업 수준 실패(빈 집기, 잘못 놓기)는 막지 못한다.

| 연구 | 학습 정책 | 고전 제어 | 결합 동기 |
|---|---|---|---|
| Cheng et al. 2019, AAAI | RL 정책 → 행동 $u_{RL}$ | CBF-QP가 보정항 $u_{CBF}$를 더함($u = u_{RL} + u_{CBF}$). GP로 동역학 불확실성 반영. CBF가 학습 방향도 이끔 | 학습 중에도 안전을 지키면서 탐색 |
| Wabersich & Zeilinger 2021, *Automatica* | 임의의 학습 제어기 | MPC 형태 예측 안전 필터: 안전 집합으로 돌아올 수 있는 행동만 허용 | 학습 제어기와 무관하게 비선형 제약 시스템의 제약 만족 보장 |
| Dalal et al. 2018 (Safety Layer) | RL → 행동 | 제약을 행동에 대해 선형 근사 → 닫힌 형태 보정 | QP 없이 가벼운 보정 |
| Alshiekh et al. 2018, AAAI (Shielding) | RL | 시간 논리 명세로 만든 shield가 위반 행동 차단 | 이산 행동·형식 명세 |

### P4. 스위칭/상태기계 구조

$$u = \begin{cases}\pi_\theta(o) & \sigma(x) = \text{learned}\\[2pt] u_{\text{rule}}(x) & \sigma(x) = \text{rule}\end{cases}$$

감시자(supervisor) $\sigma$가 상황에 따라 학습 정책과 규칙 제어기 중 하나를 고른다. 판단 근거는 상태가 안전 영역 안인가(Simplex), 인식 불확실성이 큰가(GUAPO), 작업 단계가 어디인가(FSM, 행동 트리), 실패 징후가 있는가(런타임 감시)이다.

```
                  ┌──────── 감시자 σ (규칙: 안전 영역 / 불확실성 / 작업 단계 / 실패 감지) ─────────┐
                  ▼                                                                                │
 o ──┬─► [ 학습 정책 π_θ ] ──┐                                                                     │
     │                       ├─[ 모드 선택 + 전환 완화 ]──► [ 하위 제어기 ] ──► 로봇 ──► x ────────┘
     └─► [ 규칙 제어기 ] ────┘
```

**장점.** 모드마다 따로 검증할 수 있고 해석이 쉽다. 검증된 제어기를 안전망으로 둘 수 있다.
**단점.** 전환 순간 행동이 불연속이 되고, 문턱 근처에서 떨림(chattering)이 생긴다. 감시자의 기준과 문턱을 정하는 일이 어렵다. 학습 정책은 다른 모드가 남긴 상태를 본 적이 없을 수 있다.

| 연구 | 학습 | 규칙·고전 | 결합 동기 |
|---|---|---|---|
| Simplex (Seto et al. 1998; Sha 2001) | 고성능 제어기(HPC). 형식 검증은 안 된 제어기 | 고신뢰 제어기(HAC) + 결정 논리: HPC 아래의 상태가 HAC가 정한 안정 영역을 벗어나려 하면 HAC가 넘겨받음 | 검증하지 못한 제어기 개선분을 안전하게 운용 |
| Lee et al. 2020, ICRA (GUAPO) | 불확실 영역 $\hat S_u$ 안의 RL | 영역 밖에서는 모델 기반 제어기(RMP 기반 끌개)가 $\hat S_u$ 중심으로 데려감. $\hat S_u$는 자세 추정기(DOPE)의 불확실성으로 만듦. 전환은 양방향 | 확실한 곳은 모델로 빠르게, 불확실한 곳만 학습 |
| Johns 2021, ICRA (Coarse-to-Fine) | 병목 자세 추정(자기지도 학습) + 마지막 보정 네트워크 | 병목 자세까지 직선 경로로 이동한 뒤 시연의 말단 속도를 그대로 재생 | 넓은 공간 이동은 단순 경로로, 정밀 접촉 구간만 시연으로 |
| He et al. 2024, RSS (ABS) | 민첩 정책, 회복 정책(RL), 전환 판단(학습한 reach-avoid 가치망) 모두 학습 | — | 전환 기준까지 학습한 대조 사례. 형식적 보장은 없고, 준정적 장애물에서만 일반화된다고 스스로 밝힘 |
| 런타임 실패 감지: Xu et al. 2025 (FAIL-Detect), Agia et al. 2024 (Sentinel), Zheng et al. 2026 (Rewind-IL) | IL 정책 | 감지 점수 > 문턱 → 정지·회복·되감기 | 실패 데이터 없이 실패를 감지해 규칙 모드로 넘김 |

작업 순서를 상태기계 대신 행동 트리(Behavior Tree)로 짜고 잎 노드에 학습 기술을 두는 방식도 같은 계열이다(Colledanchise & Ögren 2018).

### P5. 하이브리드(매개변수화) 행동 공간: Parameterized Action Space

$$a = (k,\ \theta_k),\qquad k \in \{1,\dots,K\}\ (\text{기본 동작 종류}),\quad \theta_k \in \mathbb R^{d_k}\ (\text{매개변수})$$

정책은 "어떤 기본 동작을 어떤 매개변수로"만 고르고, 기본 동작(motion primitive)은 손으로 짠 제어기가 실행한다. 정책의 결정 주기는 기본 동작 하나가 끝나는 주기라서 일정하지 않다.

```
 o ──► [ 학습 정책 ] ──► k   (이산: 집기 / 밀기 / 놓기 / ...)  ──► [ 기본 동작 라이브러리 ]
                    └──► θ_k (연속: 위치, 각도, 거리)          ──►   prim_k(θ_k): IK·궤적·집게 스크립트 ──► 로봇
```

**장점.** 긴 작업에서 탐색이 효율적이고, 기본 동작의 안전성을 미리 검증할 수 있으며, 해석이 쉽다.
**단점.** 기본 동작 바깥의 행동은 할 수 없다. 실행 중 되먹임이 약해 접촉 변동에 취약하다. 기본 동작을 설계하는 비용이 든다.

| 연구 | 학습 | 규칙 | 결합 동기 |
|---|---|---|---|
| Zeng et al. 2018, IROS (VPG) | RGB-D 높이맵 → 밀기·집기의 픽셀별 Q값 | 고른 픽셀·방향에서 스크립트 밀기·집기 | 탐색 공간을 "픽셀 × 방향"으로 줄임 |
| Zeng et al. 2020, CoRL (Transporter Networks) | 영상 → 집는 자세 + 놓는 자세 | 집기·놓기 기본 동작 | 공간 대칭을 활용해 소량 시연으로 학습 |
| Mahler et al. 2017, RSS (Dex-Net 2.0) | 깊이 영상 → 파지 후보의 성공 확률 | 파지 후보 샘플링 + 실행 | 해석적 파지 지표로 대량 합성 데이터 생성 |
| Nasiriany et al. 2022, ICRA (MAPLE); Dalal et al. 2021, NeurIPS (RAPS) | 상태 → 기본 동작 종류 + 매개변수 | 미리 만든 기본 동작 | 긴 작업에서 RL 탐색 효율 |

이론 틀은 parameterized action MDP다(Masson et al. 2016; Hausknecht & Stone 2016).

### P6. 고전 제어기 안의 학습 요소: Learning for Control

정책을 학습하는 대신, 제어 법칙은 그대로 두고 그 안의 모델·비용·이득을 학습한다.

$$\dot x = f_{\text{nom}}(x,u) + \hat f_\theta(x,u),\qquad u = \mathrm{MPC}\big(f_{\text{nom}} + \hat f_\theta\big)\ \ \text{또는}\ \ u = \text{비선형 제어}\big(f_{\text{nom}} + \hat f_\theta\big)$$

```
 상태 x ──► [ 고전 제어기 (MPC / 비선형 추종 / 임피던스) ] ──u──► 로봇
                    ▲
          [ 학습 요소: 잔여 동역학 f̂_θ, 비용, 이득 스케줄 ]
```

**장점.** 안정성 해석의 틀이 유지된다. **단점.** 고전 제어기의 구조가 맞지 않는 작업(영상만으로 하는 조작)에는 쓰기 어렵다.

| 연구 | 학습 | 고전 | 결합 동기 |
|---|---|---|---|
| Williams et al. 2017, ICRA (MPPI) | 신경망 동역학 모델 | 샘플링 기반 MPC(MPPI) | 공격적 주행(AutoRally) |
| Shi et al. 2019, ICRA (Neural Lander) | 지면 효과 등 잔여 공력(DNN, 스펙트럼 정규화) | 비선형 추종 제어기 | 안정성 증명을 유지하면서 모델 오차 보정 |
| O'Connell et al. 2022, *Science Robotics* (Neural-Fly) | 바람 조건에 적응하는 표현 | 적응 비선형 제어 | 강풍 속 비행 |
| Buchli et al. 2011, IJRR | 임피던스 이득 스케줄(PI²) | 가변 임피던스 제어 | 작업에 맞는 강성을 학습 |

정리 문헌: Hewing et al. 2020 (학습 기반 MPC).

### P7. 학습 시점의 결합: 고전 교사 → 학습 학생 (Privileged Teacher–Student)

$$\theta^* = \arg\min_\theta\ \mathbb E_{s\sim d}\Big[\ \ell\big(\pi_\theta(o(s)),\ \pi_{\text{expert}}(s_{\text{priv}})\big)\Big]$$

교사는 정답 상태(특권 정보)를 아는 MPC·궤적 최적화·스크립트이고, 학생은 실기에서 얻을 수 있는 관측(영상 등)만 쓴다. 실행 때는 학생만 남는다(+ P1의 하위 제어기).

```
 학습 시:  특권 상태 s_priv ──► [ 교사: MPC / 궤적 최적화 / 스크립트 ] ──a* (라벨)
                                                                             │  지도학습 (BC, DAgger)
           관측 o(s) ─────────► [ 학생 정책 π_θ ] ──a ─────────────────────┘
 실행 시:  관측 o ──► [ 학생 정책 π_θ ] ──► [ 하위 제어기 ] ──► 로봇
```

**장점.** 실행 정책은 특권 정보 없이 작동한다. 교사가 안정적이면 그 성질을 물려받는다.
**단점.** 학생이 교사보다 나아지기 어렵다. 교사가 만든 분포 밖(OOD)에서 무너진다(DAgger로 완화). 실행 시 안전 보장이 없으므로 P3·P4와 함께 써야 한다.

| 연구 | 학생 | 교사 | 결합 동기 |
|---|---|---|---|
| Levine et al. 2016, JMLR (Guided Policy Search) | 영상 → 토크 CNN 정책 | 전체 상태를 아는 시변 선형-가우시안 제어기(궤적 중심 RL). 고정 교사가 아니라 학생 정책의 상태 분포 쪽으로 반복 조정됨(BADMM) | 영상 정책을 적은 표본으로 학습 |
| Pan et al. 2018, RSS | 저가 카메라 → 조향·스로틀 | 고가 센서 + MPC | 비싼 센서 없이 MPC 수준 주행 |
| Kaufmann et al. 2020, RSS (Deep Drone Acrobatics) | 감각 입력 → 행동 | 특권 정보를 쓰는 MPC | 시뮬레이션에서만 학습해 곡예 비행 |
| Chen et al. 2019, CoRL (Learning by Cheating) | 영상 → 경로점 | 특권 정보 정책(학습) | 2단계로 나눠 학습을 쉽게 함 |

## 2. 안전성과 물리 제약의 보장

### 2.1 다층 방어 구조

```
 [ 학습 정책 ]
     │  ① 런타임 감시     OOD·실패 감지 (일관성, 불확실성, 진행도)      ← "이 상황에서 정책을 믿어도 되나"
     │  ② 작업 규칙 검사   IK 도달성, 충돌, 작업 공간, 파지 확인         ← "이 행동이 말이 되나"
     │  ③ 안전 필터       CBF-QP, 예측 안전 필터, HJ                    ← "제약을 지키나"
     │  ④ 한계값          위치·속도·가속도·토크, 변화율                  ← "물리 한계 안인가"
     │  ⑤ 하위 제어기     포화, 임피던스, 수동성(에너지 탱크)            ← "토크가 폭주하지 않나"
     ▼  ⑥ 하드웨어 안전   보호 정지, 비상 정지, 힘·출력 제한             ← "위가 모두 틀려도 다치지 않나"
 [ 로봇 ]
```

위층일수록 학습 정책 고유의 위험(OOD, 환각)을, 아래층일수록 물리 위험(토크 폭주, 충돌)을 맡는다. 아래층은 위층보다 단순하고 검증하기 쉬워야 한다.

### 2.2 위험 유형별 대응

| 위험 | 증상 | 규칙 단의 대응 | 참고 |
|---|---|---|---|
| OOD | 시연에 없던 상태에서 그럴듯하지만 틀린 동작을 반복 | 불확실성·일관성·진행도 감시 → 정지, 회복, 사람 호출 | FAIL-Detect, Sentinel, Rewind-IL |
| 환각·비현실 행동 | 도달 불가 자세, 충돌 경로, 물체 없이 집기 | 실행 전 IK 도달성·충돌·작업 공간 검사, 파지 확인(집게 각도·손목 하중) | 산업 관행 |
| 불안정 토크·떨림 | 큰 행동 변화, 고주파 진동 | 위치 기반 행동 공간 + 임피던스, 변화율 제한, 저역 통과, 에너지 탱크 | Ferraguti et al. 2013 |
| 제약 위반 | 관절 한계, 속도, 장애물 거리 | CBF-QP, 예측 안전 필터, HJ 도달 가능성 | Ames 2019, Wabersich 2021, Fisac 2019 |

### 2.3 Control Barrier Function (CBF)

안전 집합을 $\mathcal S = \{x : h(x) \ge 0\}$로 두고, 제어 아핀 계 $\dot x = f(x) + g(x)u$에서 다음 QP를 매 주기 푼다.

$$u^* = \arg\min_u\ \|u - u_\theta\|^2\quad \text{s.t.}\quad L_f h(x) + L_g h(x)\,u \ \ge\ -\alpha\big(h(x)\big),\qquad u_{\min} \le u \le u_{\max}$$

$\alpha$는 class-$\mathcal K$ 함수(보통 $\alpha(h) = \gamma h$)다. 경계에서 멀면 제약이 비활성이라 $u^* = u_\theta$이고, 경계에 가까워질수록 경계 쪽으로 향하는 성분만 줄인다.

구현 시 주의할 점은 네 가지다.
1. 위치 제약처럼 상대 차수가 2 이상이면 1차 CBF로는 입력이 제약에 나타나지 않는다. 고차 CBF(HOCBF, ECBF)를 쓴다.
2. 입력 한계와 CBF 제약을 동시에 만족하는 해가 없으면 QP가 풀리지 않는다. 여유 변수(slack)를 두거나 백업 제어기로 넘긴다.
3. 모델이 틀리면 보장이 깨진다. 견고 CBF를 쓰거나 GP로 불확실성을 반영한다(Cheng et al. 2019).
4. 제약이 켜지고 꺼지는 순간 행동이 꺾인다. 3.2절의 완화 방법을 함께 쓴다.

### 2.4 예측 안전 필터 (Predictive Safety Filter)

$$\min_{u_{0:N-1}}\ \|u_0 - u_\theta\|^2\quad \text{s.t.}\quad x_{i+1} = f(x_i, u_i),\ \ x_i \in \mathcal X,\ \ u_i \in \mathcal U,\ \ x_N \in \mathcal X_f$$

첫 입력만 학습 행동에 가깝게 하고, 나머지 입력열은 "이 행동 뒤에도 안전 집합 $\mathcal X_f$로 돌아올 수 있다"는 백업 계획이다. $u_0$만 적용한다(Wabersich & Zeilinger 2021). 앞을 내다보므로 CBF보다 덜 근시안적이지만 계산이 무겁다.

### 2.5 HJ 도달 가능성 기반 최소 개입 전환

안전 가치함수 $V(x)$를 미리 계산해 두고, $V(x) > \epsilon$이면 학습 정책을, 아니면 안전 제어기 $u_{\text{safe}} = \arg\max_u \nabla V(x)^\top f(x,u)$를 쓴다(Fisac et al. 2019). Fisac et al.은 여기에 더해, 계산한 보장을 믿을 근거(모델 신뢰도)가 떨어지면 경계가 아니어도 개입하는 베이즈 방식의 판단을 둔다. 고차원 계에서는 직접 계산이 어려워 저차원 모델이나 학습 근사를 쓴다. P3(필터)와 P4(스위칭)의 경계에 있는 방식이다.

### 2.6 한계값 자르기의 구현 세부

- **관절 위치.** 하드 한계보다 안쪽에 소프트 한계를 둔다. 자르는 대상은 목표값이지 측정값이 아니다.
- **속도·가속도·저크.** 한 주기의 목표 변화를 $|\Delta q^*| \le \dot q_{\max}\,\Delta t$로 묶는다(변화율 제한). 가속도·저크도 같은 방식이다.
- **성분별 자르기와 벡터 축척.** 관절마다 따로 자르면 말단 경로의 방향이 바뀐다. 방향을 지키려면 벡터 전체를 같은 비율로 줄인다.
- **토크 포화.** 하위 제어기 출력 단에서 자르고, 적분기가 있으면 와인드업 방지를 함께 둔다.
- **작업 공간·말단 속도·힘.** 산업용·협동 로봇은 제어기 안전 기능(관절·TCP 속도와 힘 한계, 보호 정지)으로 이미 갖고 있다. 사람과 함께 일하는 경우의 힘·출력 제한 기준은 ISO 10218과 ISO/TS 15066이다.
- **감시 시간(watchdog).** 정책 명령이 정해진 시간 안에 오지 않으면 마지막 목표를 유지한 뒤 정지한다.

### 2.7 회복 제어기 (Recovery Controller)

- **규칙 회복.** 안전 자세로 후퇴, 다시 집기, 정지 후 사람 호출. 실기에서 가장 흔하다.
- **학습 회복.** 회복 정책 자체를 학습한다(ABS의 회복 정책).
- **되감기.** 검증된 안전 상태로 되돌린 뒤 정책 상태를 비우고 다시 추론한다(Rewind-IL: "rewinds execution to the latest verified safe state before restarting inference from a clean policy state").
- **공통 주의.** 회복이 끝나 학습 정책으로 돌아갈 때 행동 큐와 관측 이력을 비워야 한다. 비우지 않으면 정책이 회복 전의 계획을 이어 간다.

## 3. 구현 고려사항

### 3.1 주기 불일치

| 층 | 전형적 주기 | 예 |
|---|---|---|
| 대형 정책(VLA) 추론 | 1~10 Hz, 행동 청크 단위 | 청크를 비동기로 생성 |
| 조작 IL·RL 정책 | 10~50 Hz | Diffusion Policy 10 Hz, VICES 20 Hz, ACT 50 Hz |
| 보행 RL 정책 | 100~200 Hz 사례도 있음 | Hwangbo 2019 보행 200 Hz |
| 관절·말단 하위 제어 | 0.1~1 kHz | Diffusion Policy 실험 UR5 125 Hz, VICES 토크 500 Hz, UR e-Series 서보 500 Hz, Franka FCI 1 kHz (제조사 사양) |
| 구동기 전류 루프 | 수 kHz 이상 | 드라이브 내부 |

해결 방법은 다음과 같다.

1. **영차 유지(ZOH) 대신 보간.** 정책 목표를 하위 주기로 선형·3차 Hermite·최소 저크 보간한다. Diffusion Policy는 "predicts robot commands at 10 Hz and these commands then linearly interpolated to 125 Hz for robot execution"이라고 적었다(9쪽) [저장소 원문]. 이 저장소의 `sim/wall3/scene.py`도 20 Hz 관절 목표를 1 kHz 물리 50스텝에 선형 보간한다. 목표를 한 주기 동안 그대로 두면 강성이 큰 UR10e 서보(kp 5000)가 20 Hz마다 1~2 ms씩 힘 한계에 부딪혀 손에 든 벽돌이 돌아갔기 때문이다.
2. **행동 청크와 겹침 처리.** 미래 행동 열을 한 번에 내고, 겹치는 청크를 시간 가중 평균하거나(ACT의 temporal ensembling) 일부만 실행하고 다시 예측한다(Diffusion Policy의 receding horizon). Diffusion Policy는 위치 제어 행동이 지연 4스텝까지 성능을 유지했고, 속도 제어가 지연에 더 민감했다고 보고했다 [저장소 원문].
3. **비동기 추론.** 추론 시간이 제어 주기보다 길면, 현재 청크를 실행하는 동안 다음 청크를 만든다. 청크 경계의 연속성을 지키는 방법은 두 가지다. RTC(Black et al. 2025)는 실행이 확정된 앞부분을 고정(freezing)하고 나머지만 새로 채운다(inpainting). SmolVLA는 현재 큐가 실행되는 동안 다음 청크를 시작하고, 겹치는 구간을 합쳐서 쓴다(고정·채우기 없음).
4. **학습 때 실기 하위 제어를 그대로 모사.** 같은 decimation, 같은 PD 이득, 같은 보간 방식, 지연 무작위화. 구동기 응답이 복잡하면 actuator network로 모델링한다(Hwangbo et al. 2019).
5. **시각 동기화.** 관측에 타임스탬프를 붙이고 오래된 관측은 버린다. 영상과 관절값의 시각 차이를 확인한다.
6. **실시간 분리.** 하위 제어 루프는 실시간 스레드나 드라이버에 두고, 정책은 별도 프로세스에서 돌리며, 하위 루프는 최신 목표만 읽는다. 명령이 끊기면 watchdog이 정지시킨다.

### 3.2 부드러운 전환 (Smooth Transition)

1. **혼합(blending).** $u = \big(1-\alpha(t)\big)\,u_A + \alpha(t)\,u_B$, $\alpha$를 코사인이나 시그모이드로 0.1~0.5 s 동안 0→1로 올린다.
2. **Bumpless transfer.** 새 제어기의 기준값과 적분 상태를 전환 순간의 실제 상태·출력에 맞춘다(Åström & Hägglund 2006). 예: 규칙 제어기로 넘길 때 목표를 "현재 측정 자세"로 초기화.
3. **히스테리시스와 최소 체류 시간.** 켜는 문턱과 끄는 문턱을 다르게 두고, 전환 뒤 일정 시간은 다시 전환하지 않는다. 문턱 근처의 떨림을 막는다.
4. **현재 상태에서 다시 계획.** 새 궤적을 측정 위치·속도에서 시작해 속도를 연속으로 잇는다(최소 저크 궤적).
5. **전환 구간의 변화율·저크 제한 강화.**
6. **접촉 전환은 임피던스로 완충.** 접촉 직전에 강성을 낮추고, 이득은 계단이 아니라 경사로 바꾼다. 가변 강성은 에너지 탱크로 수동성을 지킨다(Ferraguti et al. 2013).
7. **정책 상태 초기화.** 학습 정책으로 돌아올 때 행동 큐와 이력을 비우거나 현재 상태로 warm-start한다(Rewind-IL).
8. **CBF 필터의 꺾임 완화.** 여유 변수가 있는 soft 제약, 완만한 $\alpha$, 필터 출력의 저역 통과.
9. **측정.** 전환 순간의 최대 토크, 저크, 접촉력을 기록해 전환 설계를 숫자로 비교한다.

## 4. 이 프로젝트(모방학습 조적)에의 대응

| 패턴 | 이 저장소 |
|---|---|
| P7 | 정답 좌표를 아는 IK 스크립트 교사 → 카메라·관절값만 쓰는 학생 정책(ACT, Diffusion Policy) |
| P1 | 정책이 20 Hz로 관절 목표 6개 + 집게 1개를 냄 → UR10e 관절 서보(1 kHz 물리, 선형 보간) |
| P4 + P3 | 정책 밖 검측 G1(잡기 확인)·G2(놓기 전 보정)·G3(놓은 뒤 재배치) = 규칙 감시자 + 규칙 회복 |
| P2 | 쓰지 않음. G2 보정을 학습 잔차로 바꾸면 ResiP 계열이 됨 |

앞서 정리한 "조적 로봇은 학습이어야만 하는가"와 연결하면, 이 문헌들은 대체로 "불확실한 부분은 학습, 확실한 부분은 모델·규칙"(GUAPO)이라는 분담을 지지한다. 로봇 학습 분야의 일반적인 질문은 "학습이어야만 하는가"가 아니라 "어디를 학습에 맡기고 어디를 규칙으로 지킬 것인가"다.
